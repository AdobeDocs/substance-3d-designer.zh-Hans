# 用户界面问题

本页列出了与Substance 3D Designer的[用户界面](../../interface/interface.md)相关的技术问题，并为每项问题提供了故障排除步骤。

## 界面的比例不正确

<table>
<tr style="border: 0;">
<td style="border: 0;" valign="top">

**![(出错)](../../assets/error.svg)问题**

用户界面元素太小或太大。

</td>
<td style="border: 0;" valign="top">

**![(滴答)](../../assets/check.svg)建议的步骤**

Designer从OS *获取用户界面元素*&#x200B;的特定比例。 因此，对用户界面缩放比例的任何调整都应在操作系统的显示设置中完成。

为确保在Designer中正确应用显示设置，请在更改这些设置后&#x200B;*注销您的OS用户会话*&#x200B;并重新登录。

</td>
</tr>
</table>
