# Python 编辑器

Substance 3D Designer包含一个&#x200B;**脚本编辑器**，可让用户直接&#x200B;**在Designer中测试Python代码**&#x200B;并获取其&#x200B;**控制台输出**。

![Python编辑器](../../assets/demo-pythoneditor.png "Python编辑器")

该编辑器具有“**查找和替换**”功能，可在编辑器菜单栏的“*编辑>查找……*”项中访问或通过按&#x200B;*Ctrl+F*&#x200B;访问。

![在Python编辑器中查找和替换](../../assets/demo-pythoneditor-2.png "在Python编辑器中查找和替换")

按照Python编辑器的&#x200B;**测试** **目的**&#x200B;的精神，用户可以通过按编辑器工具栏中的“*运行*”按钮（或按&#x200B;*F5*）或仅通过按“*运行选区*”按钮（或按“*Ctrl+Enter*”）测试&#x200B;**当前选区**。

![在Python编辑器中运行选定的代码](../../assets/demo-pythoneditor-3.png "在Python编辑器中运行选定的代码")
