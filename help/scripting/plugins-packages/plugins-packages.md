# 增效工具包

支持Python包以创建插件来扩展应用程序。

它们是具有sdplugin扩展名的单个文件，包含插件需要工作的所有内容。 对于开发人员，包简化了插件共享和向用户分发的过程。 对于用户来说，包更易于安装和管理。

## 安装插件包

![插件管理器](../../assets/screenshot-from-2019-07-18-11-48-56.png "插件管理器")

插件包是使用<b>插件管理器</b>在<b>工具</b>菜单中进行安装的：

1. 单击<b>安装</b>按钮，然后选择要安装的插件包
1. 插件将安装在主目录中，位于每个操作系统的插件的默认路径中
1. 安装插件后，将自动加载它
