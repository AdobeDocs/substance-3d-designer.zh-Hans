# 脚本

可以通过编写插件来控制应用程序。 可以使用版本&#x200B;**3.9**&#x200B;以&#x200B;**Python**&#x200B;脚本语言编写插件。 应用程序中提供的Python API允许直接从脚本访问和使用许多功能。

[Python](https://www.python.org/)是一种脚本语言，广泛应用于许多行业。 它有助于构建自动化、工作流加速和资产管理工具等示例。 可以从包含&#x200B;**帮助** > **脚本文档……**&#x200B;操作的主菜单访问API文档。
