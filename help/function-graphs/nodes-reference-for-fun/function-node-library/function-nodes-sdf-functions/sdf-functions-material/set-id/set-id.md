# 设置材料ID

<table>
<tr style="border: 0;">
<td width="33.33%" style="border: 0;" valign="top">

<b>In：</b> 3D Function > Material

</td>
<td width="100.00%" style="border: 0;" valign="top">

## 描述

设置SDF场景的材质ID。

然后，可以在[形状飞溅v2](../../../../../../compositing-graphs/nodes-reference-for-com/node-library/texture-generators/patterns/shape-splatter-v2/shape-splatter-v2.md)的&#x200B;*Splatter UVW*&#x200B;输出中检索所有飞溅的SDF形状的此值。

</td>
</tr>

## 输入

|                          |                        |
|--------------------------|------------------------|
| <b>SDF场景</b> *浮动* | 输入SDF场景。 |
| <b>ID</b> *整数* | 要设置的整数ID。 |
