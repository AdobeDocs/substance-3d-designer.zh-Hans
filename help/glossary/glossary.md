# 了解Designer中使用的术语和概念。

## #&#x200B;

|  |  |
| --- | --- |
| <b><span id="three-d-scene" data-preserve-html="true"></span>3D场景</b> | 表示3D空间的可视化和为其制作动画所涉及的对象和数据集合：<ul data-preserve-html="true"> <li data-preserve-html="true">[网格](#mesh)</li> <li data-preserve-html="true">[材质](#material)</li> <li data-preserve-html="true">相机</li> <li data-preserve-html="true">光源</li> <li data-preserve-html="true">动画</li> <li data-preserve-html="true">模拟</li> <li data-preserve-html="true">...</li> </ul>用于存储3D场景的[常用文件格式](https://www.adobe.com/products/substance3d/discover/3d-files-formats.html)包括Pixar的[USD](#usd)和Autodesk的FBX。 所有文件格式均不支持所有这些组件 |

## A

|                                                                                        |                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                               |
|----------------------------------------------------------------------------------------|-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| <b><span id="alpha" data-preserve-html="true"></span>Alpha频道</b> | 彩色图像的第四个通道，通常用于描述不透明度。 |
| <b><span id="ambient-occlusion" data-preserve-html="true"></span>环境遮蔽</b> | 环境光在曝光较少因而难以到达的表面上的衰减。 |
| <b><span id="anisotropy" data-preserve-html="true"></span>各向异性</b> | 依赖于方向的属性。 换句话说，当在不同的轴上测量或观察时，提供不同的结果。<br><br>各向异性材料的外观因它们的观察位置而异，并且各向异性滤镜并非在所有方向上都均匀应用。 |
| <b><span id="aov" data-preserve-html="true"></span>AOV</b> | 任意输出变量(AOV)是[渲染](#rendering)中使用的术语，用于描述可从渲染输出的其他数据通道，例如深度、法线或自定义数据。 |
| <b><span id="api" data-preserve-html="true"></span>API</b> | 应用程序编程接口(API)是功能和过程的集合，允许用户访问另一个应用程序的功能和过程。<br><br>API在用户与程序之间提供受控且安全的层。 它还可以使用另一种编程语言来使程序更易于交互且更易于访问。<br><br>Designer提供了一个[Python API](../scripting/scripting.md)，通过此API可轻松访问其各种功能，以便处理数据、构建自定义工具和加快工作流程。 |
| <b><span id="atomic-node" data-preserve-html="true"></span>原子节点</b> | 图的基本构成要素。 所有[实例化](#instance-node)都可以细分为原子节点图形。<br>每个图形类型都有自己的一组原子节点。 |

## B

|                                                                                          |                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                      |
|------------------------------------------------------------------------------------------|----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| <b><span id="baking" data-preserve-html="true"></span>烘焙</b> | 从3D模型计算信息并将结果存储到[纹理](#texture)的过程。 数据根据模型的[UV](#uv)置入纹理中。 |
| <b><span id="base-color" data-preserve-html="true"></span>基色</b>(反照率) | 使用PBR金属粗糙度[着色](#shader)模型定义的[材质](#material)的通道。<br>Base color指定没有任何光照信息的表面的颜色。<br><br>不应将其与[Diffuse](#diffuse)混淆。 |
| <b><span id="base-parameter" data-preserve-html="true"></span>基本参数</b> | 计算[位图](#bitmap)的Substance图中所有节点都通用的参数。<br><br>其中包括位图的核心方面，例如其分辨率（[输出大小](#output-size)）和[位深度](#bit-depth) （[输出格式](#output-format)），或者位图的计算方式，例如[拼贴](#tiling)模式。<br><br>基参数通常是[从上游的其他节点或承载该节点的图形继承](#inheritance)。 |
| <b><span id="bilinear-filtering" data-preserve-html="true"></span>双线性过滤</b> | [纹理样本](#texture-sampling)在像素的中心未准确执行时，计算机成像中使用的插值过程。<br><br>例如，在放大图像时可能会发生这种情况。 |
| <b><span id="bit-depth" data-preserve-html="true"></span>位深度</b> | 用于存储纹理中像素值的位数。 较高的位深度允许编码更多值，从而产生更平滑的渐变。<br><br>根据值的类型，可以使用不同的位深度： -整数值可以使用8位（0到255）或16位（0到65,535）进行编码。 -浮点值可以使用16位（+32767.9999到 — 32768.0 ）或32位（–3.4E+38到+3.4E+38）进行编码<br><br>低动态范围图像使用整数值对0到1之间的步骤进行编码。 高动态范围图像使用浮点值对原始数值进行编码。<br><br>在图形中，位深度由[Output Format](#output-format)参数控制。 |
| <b><span id="bitmap" data-preserve-html="true"></span>位图</b> | 数字图像。 最常见的图像类型有两种：<ul data-preserve-html="true"> <li data-preserve-html="true">灰度图像只有一个渠道：明亮度(L)；</li> <li data-preserve-html="true">彩色图像有三个通道：红色、绿色和蓝色(RGB)。 可能存在第四个Alpha值： [Alpha](#alpha) (A)，常用于不透明度。 Designer中的彩色图像始终是RGBA。</li> </ul>  位图可以看作是值的网格。 该网格的每个单元是一个像素，它是“图像元素”的简称。 像素为每个通道存储一个值。 该值的类型取决于位图的[位深度](#bit-depth)。 |

## C

|                                                                                                                                          |                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                        |
|------------------------------------------------------------------------------------------------------------------------------------------|------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| <b><span id="cache" data-preserve-html="true"></span>缓存</b> （内存） | 数据的集合 — 例如， 节点的[基本参数](#base-parameter)和输出图像 — 存储在内存中以便重复使用。<br><br>通过让[Substance 引擎](#substance-engine)仅重新计算图形中已更改的部分，缓存可大大加快图形计算。 调整节点连接和参数时，它前面的所有节点不受这些更改的影响，因此不需要再次[计算](#evaluation)来更新图形。 将改用其缓存。<br><br>在大图形中处理高分辨率和位深度时，缓存可能会占用大量内存。 |
| <b><span id="channel-packing" data-preserve-html="true"></span>频道打包</b> | 一种优化技术，其中单独的图像被打包到单个彩色图像的RGB(A)通道中。<br><br>例如，RMA纹理是[粗糙度](#roughness)映射(R)、金属度映射(M)和[环境遮蔽](#ambient-occlusion)映射(A)，所有这些都封装成一种颜色纹理。<br><br>另一种常用的技术是将灰度纹理打包到[法线图](#normal-map)的蓝色通道中，因为蓝色通道（即法线矢量的“Up”分量）可以在运行时重新计算。<br><br>[RGBA合并](../compositing-graphs/nodes-reference-for-com/node-library/filters/channels/rgba-merge/rgba-merge.md)节点对于实现此技术非常有用。 |
| <b><span id="color-space" data-preserve-html="true"></span>色彩空间</b> | 颜色范围表示方式的定义。<br>对特定颜色进行数字编码和解码需要这样的定义才能理解所使用的数字。<br><br>图像文件使用指定的色彩空间存储颜色值，以便在支持该色彩空间的显示器上忠实再现这些颜色。 显示器具有特定的色彩再现能力，使其能够完全或部分支持给定的色彩空间。<br><br>原始数据 — 例如 [法线映射](#normal-map) — 始终在线性色彩空间中编码和解码，因为这些颜色不是为了可视化，因此不应对该数据应用任何变换。<br><br>sRGB是广泛支持的色彩空间。 其他流行的色彩空间包括Adobe RGB、Rec. 2100和ProPhotoRGB。 |
| <b><span id="cooking" data-preserve-html="true"></span>烹饪</b> （<span id="compilation" data-preserve-html="true"></span>编译） | 将数据翻译成另一种语言的过程，以便可以快速、高效地执行。<br>计算Substance图的结果需要首先对其进行编译。 编译是图形[评估](#evaluation)过程的一部分。<br><br>此编译是在拼合的图形上执行的，这意味着所有[实例节点](#instance-node)都将被其源图形“替换”，以便保留一个较大的图形，该图形就是编译的图形。<br><br>编译的图形不可编辑。 如果公开的参数为[动态](#dynamic-parameter)，则这些参数仍可用，而[静态](#static-parameter)参数被锁定并隐藏。 |
| <b><span id="culling"></span>剔除</b> | 一种用于[渲染](#rendering) [3D场景](#three-d-scene)的优化技术，当几何不可见时，它从渲染的计算中移除几何。<br><br>这可能包括相机丰满截止（*丰满截止*）外的对象或多边形，朝向相机相反方向（*背部截止*）或完全被其他不透明对象（*遮蔽截止*）隐藏。 |

## D

|                                                                                        |                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                               |
|----------------------------------------------------------------------------------------|---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| <b><span id="dependency" data-preserve-html="true"></span>依赖关系</b> | 文件A由其他文件B使用，导致文件B在文件A缺失时无法按预期工作。<br><br>[包](#package)的依赖关系可以是其他包，因为它引用其中的图形、图像文件、字体等。<br><br>包存储其依赖关系的路径，如果在该路径中找不到依赖关系，则会引发警告。 缺少依赖关系还可能导致图形中出现[虚影实例节点](#ghost-instance-node)。 |
| <b><span id="diffuse" data-preserve-html="true"></span>扩散</b> | 使用PBR光泽度[材料](#shader)模型定义的[着色](#material)的声道。 漫射指定光照时的表面颜色。<br><br>不应将其与[Base color(反照率)](#base-color)混淆。 |
| <b><span id="directx" data-preserve-html="true"></span>DirectX</b> | 用于处理多媒体内容的API集合。 其3D API Direct3D广泛用于视频游戏开发和其他3D行业。<br><br>Direct3D将纹理的原点(即(0， 0)坐标)放在&#x200B;*左上*(Y-down)，而[OpenGL](#opengl)API将其放在&#x200B;*左下*(Y-up)。<br><br>这意味着DirectX[法线图](#normal-map)与OpenGL相比，具有&#x200B;*倒置绿色通道*。 事实上，绿色通道承载了法向量的Y坐标。 |
| <b><span id="displacement" data-preserve-html="true"></span>位移</b> | 移动3D模型[顶点](#vertex)的过程，通常沿其[正常](#normal)移动。<br><br>位移通常与[曲面细分](#tessellation)和[法线图](#normal-map)结合使用，以在表面上构建更精细的细节。 |
| <b><span id="dynamic-parameter" data-preserve-html="true"></span>动态参数</b> | 值可能更改的参数。 换句话说，任何非常量的参数都是动态的。<br><br><br>这包括公开参数、受公开参数影响的任何参数以及受[纹理中的采样](#texture-sampling)影响的任何参数值。<br><br>与[静态参数](#static-parameter)相反，在将图形编译为[Sbsar 文件](#sbsar-file)后，可以动态调整动态参数的值。 |

## E

|                                                                          |                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                               |
|--------------------------------------------------------------------------|-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| <b><span id="evaluation" data-preserve-html="true"></span>评估</b> | 解决图形中数据和参数传播的过程。 评估验证图表及其连接的有效性，应用[继承](#inheritance)和[烹调](#cooking)图表。<br><br>在图形视图中，如果连接未计算，则用虚线表示。<br>计算会将连接转换为实线。<br><br><br>每次在图形中调整参数时，承载此参数的节点和下游的所有节点都处于[无效](#invalidation)状态，需要重新评估才能进行[渲染](#rendering)。 |

|                                                                         |                                                                                                                                  |
|-------------------------------------------------------------------------|----------------------------------------------------------------------------------------------------------------------------------|
| <b><span id="filter" data-preserve-html="true"></span>筛选器</b> （节点） | [节点](#node)，将修改应用于图像（例如，变形）或从中提取信息（例如，蒙版）。 |

## G

|                                                                                            |                                                                                                                                                                                                                                                                                                                                                                                        |
|--------------------------------------------------------------------------------------------|----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| <b><span id="ghost-instance-node" data-preserve-html="true"></span>Ghost实例节点</b> | 将引用[子图](#subgraph)的[实例化](#instance-node)作为幽灵实例化加载，但找不到该路径，即缺少[依赖关系](#dependency)。通过解析缺少的依赖项并重新加载[包](#package)，<br><br>实例化将恢复到其预期状态。 |
| <b><span id="glossiness" data-preserve-html="true"></span>光泽度</b> | 使用PBR光泽度[材料](#shader)模型定义的[着色](#material)的声道。 光泽度指定表面的粗糙度 — 即Height的微小变化，也称为&#x200B;*小平面*。<br><br>高光泽度产生平滑的外观，而低光泽度产生粗糙的哑光外观。<br><br>它是[粗糙度](#roughness)的反向。 |

## 高

|                                                                                |                                                                                                                                                                                                                                                                                                                                                                                                                                                                           |
|--------------------------------------------------------------------------------|---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| <b><span id="histogram" data-preserve-html="true"></span>直方图（图像）</b> | 在图像上下文中，直方图表示给定范围内的值的总体情况 — 通常为[0， 1]。<br><br>此总体情况是使用垂直条直观显示的，图像中显示的值越多，表示该值的条形越大。<br>条形图沿水平方向从低值（暗）分布到高值（亮）。<br><br>彩色图像的直方图通常与其每个通道的直方图重叠 — 通常是R、G、B。 |

## I

|                                                                                |                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                   |
|--------------------------------------------------------------------------------|---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| <b><span id="inheritance" data-preserve-html="true"></span>继承</b> | 在图形环境中，继承描述从上游节点或其父图形获取参数值的节点的特性。<br><br>继承的参数包括[分辨率](#resolution) （[输出大小](#output-size)）、[位深度](#bit-depth) （[输出格式](#output-format)）和[拼贴](#tiling)模式。<br><br>在此[专用页面](../compositing-graphs/inheritance-compositing/inheritance-in-substance-compositing-graphs.md)中了解有关继承的更多信息。 |
| <b><span id="instance-node" data-preserve-html="true"></span>实例化</b> | 实例化表示图形A进入另一个图形B。在这种情况下，图形A可以称为图形B的[子图](#subgraph)。图形A中的任何更改都会传播到表示它的所有实例化。<br><br>在图形B的上下文中，实例化为图形A的输入参数应用其自己的值集。从这种意义上讲，图形B可以承载多个实例化，这些节点都引用图形A，但每个节点将不同的值或纹理作为输入传递到图形A。<br><br>Designer库中所有不是[原子节点](#atomic-node)的节点都是实例化。 |
| <b><span id="invalidation" data-preserve-html="true"></span>无效</b> | 声明节点结果已过时的进程。<br><br>调整参数时，承载此参数的节点和下游的所有节点都无效，因此需要再次[计算](#evaluation)和[渲染](#rendering)。 |

## M

|                                                                      |                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                       |
|----------------------------------------------------------------------|-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| <b><span id="material" data-preserve-html="true"></span>材料</b> | 空间物质属性和行为的集合，包括表面和体积。<br>实体在3D空间中的外观由其材料定义。<br><br>材料可以用多种方式定义，并且所有定义均不支持所有属性，如折射、各向异性或光泽。 [着色器](#shader)是材料定义的特定实现。<br><br><b>重要说明：</b>术语“材料”是一个&#x200B;*总括术语*，用于表示各种内容，包括：<ul data-preserve-html="true"> <li data-preserve-html="true">[着色器](#shader)用于计算表面或体积的外观；</li> <li data-preserve-html="true">向着色器提供的[纹理](#texture)集；</li> <li data-preserve-html="true">材质ID，它是3D图元的属性，用于区分使用不同材质的零件。</li> </ul> |
| <b><span id="mesh" data-preserve-html="true"></span>网格</b> | 由[顶点](#vertex)组成的3D对象，这些顶点通过边缘连接以形成多边形（如三角形），而多边形又装配成表面。 这些曲面可以是开放的，也可以是闭合的。<br><br>这些表面的外观由分配给它们的[材质](#material)定义。<br>网格的细节级别也高度依赖于其[多边形计数](#polycount)。 |
| <b><span id="metadata" data-preserve-html="true"></span>元数据</b> | 提供有关文件本身、文件环境或任何与文件数据相关的信息的数据。<br><br>常见元数据包括文件的作者、创建和修改日期、版权和封面作品。<br><br>在Designer中，[包](#package)的内容也可以包含元数据。 例如，生成结构材料的Substance图可以具有结构物理属性的metadata。 |
| <b><span id="mipmap" data-preserve-html="true"></span>Mipmap</b> | [纹理](#texture)的较小版本，通常会自动计算。<br><br>纹理可以具有自身较小版本的金字塔，这些版本在运行时可以互换，以便使用最合适的大小来获得最佳质量和性能。<br><br>例如，以较小尺寸显示高频细节的纹理可能会产生&#x200B;*摩尔纹*&#x200B;伪影。 此外，较大的纹理可能涉及更多[纹理样本](#texture-sampling)。<br><br>术语“mipmap”源自MIP映射技术，其中MIP表示拉丁语“*parvo*”，表示“许多东西在一个小地方”。 |

## N

|                                                                                |                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                          |
|--------------------------------------------------------------------------------|--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| <b><span id="node" data-preserve-html="true"></span>节点</b> | 图形中的对象，可执行计算并输出一个或多个结果。<br><br>使用输入参数控制结果。 这些参数可以作为“属性”停放区中的控件列出，也可以作为节点本身上的输入连接器列出。<br><br>有两种主要类别的节点：[原子节点](#atomic-node)和[实例节点](#instance-node)。 |
| <b><span id="noise" data-preserve-html="true"></span>杂色</b> | 表示形状和颜色的随机或伪随机分布的非图形图像。 噪声通常用于为表面或变形添加变化。<br><br>Designer的节点库包括一系列噪声生成器，如[BnW斑点](../compositing-graphs/nodes-reference-for-com/node-library/texture-generators/noises/bnw-spots-2/bnw-spots-2.md)、[云彩](../compositing-graphs/nodes-reference-for-com/node-library/texture-generators/noises/clouds-2/clouds-2.md)、[Perlin噪声](../compositing-graphs/nodes-reference-for-com/node-library/texture-generators/noises/perlin-noise/perlin-noise.md)或[Voronoi](../compositing-graphs/nodes-reference-for-com/node-library/texture-generators/noises/voronoi/voronoi.md)。 |
| <b><span id="normal" data-preserve-html="true"></span>正常</b> | 在3D计算中，曲面的法线是一个垂直于该曲面的[归一化](#normalization)矢量，从该曲面向外延伸。<br><br>此矢量表示曲面在3D空间中的方向，可根据场景的光线和相机透视对该曲面进行[着色](#shader)。<br><br>可以对曲面应用[法线映射](#normal-map)纹理以修改其法线并添加细节。 |
| <b><span id="normal-map" data-preserve-html="true"></span>法线图</b> | [纹理](#texture)应用于表面以修改其法线。<br><br>它最常用于伪装细节，这些细节在模型几何中无法有效包含。 使用这样的映射允许除per-[vertex](#vertex)法线之外还有per-[texel](#texel)法线，从而产生更多的表面信息，从而产生更多的表面细节。<br><br>将法向量的X、Y、Z坐标分别编码为地图的红、绿、蓝通道。 根据目标图形API（[DirectX](#directx)或[OpenGL](#opengl)），可能会反转绿色通道。 |
| <b><span id="normalization" data-preserve-html="true"></span>标准化</b> | 将值范围重新映射到[0， 1]范围的过程，其中最高输入值重新映射到1.0，最低输入值重新映射到0.0。<br><br>对于矢量，标准化是将矢量的长度（或“模”）调整到1.0的值。 |
