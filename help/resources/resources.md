# 资源

资源是Substance 3D Designer包的内容。 它们用于构建、生成和预览材质和纹理数据。 资源可以分为两大类：图形资源和非图形资源。 用于创建或导入资源的方法因类型而异，您可以阅读有关[链接、导入和新资源](../resources/importing-linking-and-new/importing-linking-and-new-resources.md)的专用页面以更好地了解这一点。

### 非图形资源

非图形资源通常是图形中用作附加数据的辅助资源，或用于帮助可视化图形的结果。 存在以下类型，每个类型的文档在此部分都有一个子页面：
