# Project settings

此页面显示[Substance 3D Designer](https://www.adobe.com/cn/products/substance3d-designer.html)中的<b>项目设置</b>以及其中包含的设置。

Substance 3D Designer允许您为每个项目&#x200B;*创建首选项*，并在工作站间共享它们。 可在[首选项](../../../interface/preferences-window/preferences-window.md)窗口的<b>项目</b>选项卡中找到这些首选项。

如果您想通过使用&#x200B;*所有*&#x200B;系统上的&#x200B;*same*&#x200B;项目文件为处理同一项目的团队设置通用工作环境，此功能非常有用。

>[!NOTE]
>
> 有关在&#x200B;**生产管道**&#x200B;中设置和集成Substance 3D Designer的详细信息，我们&#x200B;*强烈推荐*，请参阅文档的[管道和项目配置](../../../pipeline-and-project-con/pipeline-and-project-configuration.md)部分。

![项目设置](project-settings.resources/2019-3-0-prefs-proj-01.png "项目设置"){zoomable="yes"}

## 配置

### 配置文件

这允许您设置Substance 3D Designer <b>配置文件</b>的路径。 配置文件使用<b>\*.sbscfg</b>扩展名，并包含项目文件列表以及设置的兼容性显示设置。

*默认： default\_configuration.sbscfg*

>[!NOTE]
>
> 您可以使用&#x200B;**—config-file**&#x200B;命令行选项通过特定的配置文件启动Designer。\
> 有关配置文件的详细信息，请参阅文档的[配置列表 — SBSCFG](../../../pipeline-and-project-con/configuration-list-sbscfg/configuration-list-sbscfg.md)页。

### 项目文件

项目文件包含许多设置，这些设置在Designer中定义工作环境的主要方面，并整理到选项卡中。 这些设置列在本页的“项目”一章中。 项目文件使用<b>\*.sbsprj</b>扩展名。

您可以在Designer中导入多个项目文件以用于您的工作环境。 存在多个项目文件时，列出的设置（例如库监视路径、别名等） 是&#x200B;*组合的*，并且唯一集值的设置由列表的&#x200B;*最后一个项目文件*&#x200B;定义。

*默认： default\_project.sbsprj（只读）， user\_project.sbsprj*

>[!NOTE]
>
> 有关在生产管道中使用项目文件的详细信息，请参阅文档的[项目配置文件 — SBSPRJ](../../../pipeline-and-project-con/project-configuration-fil/project-configuration-files-sbsprj.md)页面。

### 兼容性显示

使用最新版本Designer创建的某些节点与旧版本Substance 引擎不兼容。

<b>兼容模式</b>将突出显示&#x200B;*不*&#x200B;与所选Substance 引擎兼容的节点，并带有黄色轮廓。

*默认：Substance 引擎v7*

### 别名

别名用于&#x200B;*缩短*&#x200B;系统路径，并允许团队更高效地&#x200B;*共享*&#x200B;资源。 在整个软件&#x200B;*以及* SBS文件&#x200B;*中*&#x200B;使用了别名。

这些设置允许您&#x200B;*添加*&#x200B;和&#x200B;*编辑*&#x200B;别名。 应用别名后，*将使用以下语法替换*&#x200B;映射路径： <b>：//</b>。

示例：如果将文件夹&#x200B;*myFolder*&#x200B;中的资源&#x200B;*myResource*&#x200B;放置在位置&#x200B;*C：/Users/user/Documents*，则将此位置映射到&#x200B;*myalias*&#x200B;将导致在应用程序&#x200B;*和*&#x200B;中使用资源所属的SBS包中的&#x200B;*myalias://myFolder/myResource*&#x200B;路径。

*默认：sbs；sd-3dview-shapes；sd-3dview-maps；sd-3dview-shaders（默认项目）*

>[!WARNING]
>
> 别名是应用程序&#x200B;*的全局*。 这意味着这些路径将应用于应用程序中使用的&#x200B;*所有路径*，以及&#x200B;*加载的SBSPRJ项目设置文件*&#x200B;中的所有路径。 在设置项目环境时请记住这一点！\
> 此外，我们建议&#x200B;*不要嵌套*&#x200B;别名 — 即，为也包含在另一个别名中的路径设置别名。

### 库

此部分允许您<b>管理[库](../../../interface/the-library/the-library.md)的自定义内容</b>。

<b>添加的路径</b>列表中列出的所有文件夹的内容都将包含在库中。 对内容所做的任何更改都会反映在库中，刷新期之后即可在[首选项](../../../interface/preferences-window/preferences-window.md)窗口的[库](../../../interface/preferences-window/preferences-window.md) [选项卡](../../../interface/preferences-window/preferences-window.md)中设置。

在列表的列中，您可以找到一些选项，这些选项使您可以更精细地控制将这些文件夹的内容添加到库的方式：

* **已启用：**&#x200B;文件夹的内容显示在库中（*默认：已选中*）
* **递归：**&#x200B;所有子文件夹的内容也显示在库中（*默认：已选中*）
* **排除模式：** *名称*&#x200B;与输入Regex （正则表达式）匹配的文件&#x200B;*不*&#x200B;显示在库中（例如`wip-*`） 。 在[此处](https://doc.qt.io/qt-5/qregularexpression.html#wildcardToRegularExpression)了解有关正则表达式语法的详细信息
* **排除扩展名：** *扩展名*&#x200B;包含输入文本字符串的文件&#x200B;*不*&#x200B;显示在库中。 多个字符串应该用`;`分号分隔。 (E.g. `jpg;png;tif;fbx`)

如果将SBS包添加到库中，并且其&#x200B;**在库中可见**&#x200B;参数设置为“是”，则它包含的&#x200B;**图形**&#x200B;和&#x200B;**资源**&#x200B;可以&#x200B;*作为单独的条目显示在库中*。\
在包中创建/添加新图形或资源时，可使用此选项来定义此参数是否应在默认情况下&#x200B;**&#x200B;设置为“是”。

*默认值：已选中*

如果PSD中包含的[Photoshop](https://www.adobe.com/cn/products/photoshop.html)文档（\*.library文件）具有<b>多个图层</b>，则可以通过某个选项将*&#x200B;每个图层的内容作为单独的图像条目*显示在库中。

*默认值：已选中*

>[!NOTE]
>
> 将您的自定义资源添加到库时，由于为现有库类别设置了筛选规则，因此&#x200B;*可能不可见*。 我们建议创建&#x200B;*您自己的筛选器*（以文件夹组织），以确保在处理您的项目时可靠地找到您的内容。\
> 有关详细信息，请参阅文档的[管理自定义内容和筛选器](../../the-library/managing-custom-content/managing-custom-content-and-filters.md)部分。

### 版本控制

>[!WARNING]
>
> [性能](https://www.perforce.com/)是版本控制当前支持的&#x200B;*仅*&#x200B;工具。

请参阅[版本控制](../../../interface/preferences-window/version-control/version-control.md)页面。

**应该如何使用它？**

您应在Designer的项目文件(\*.sbsprj)中设置所有特定于项目的首选项**。 这些首选项包括：

* 切空间插件
* 库
* 别名
* 3D视图设置
* 烘焙设置
* [版本控制设置](../../../interface/preferences-window/version-control/version-control.md)

所有路径都存储在&#x200B;*相对于项目文件(.spsprj)的*&#x200B;中。 因此，可将&#x200B;**库**&#x200B;文件夹与Perforce中的项目文件放在同一位置，并具有以下子文件夹树：

* 地图/
* 网格/
* sbs/
* sbsar/
* psd/
* 3Dview/
* ...

在项目文件所在的层级上，您还可以存储切线空间插件或默认着色器。

配置文件(\*.sbscfg)应与“项目文件”一起放在“性能”工作区中。

>[!NOTE]
>
> 有关在&#x200B;**生产管道**&#x200B;中设置和集成Substance 3D Designer的详细信息，我们&#x200B;*强烈推荐*，请参阅文档的[管道和项目配置](../../../pipeline-and-project-con/pipeline-and-project-configuration.md)部分。
