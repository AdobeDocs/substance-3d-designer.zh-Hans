# 依赖项管理器

<b>依赖关系管理器</b>允许您查看包的所有依赖关系，并在出现问题时查找和修复它们。

可以通过在资源管理器中右键单击某个包并在上下文菜单中选择“依赖项管理器”选项来访问该包。
