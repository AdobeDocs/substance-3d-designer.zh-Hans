# 材料属性

[3D 视图](../../../interface/3d-view/3d-view.md)使用名为&#x200B;*着色器*的程序渲染模型表面。 着色器定义材料
使用影响模型外观的各个方面的属性列表应用到模型。

3D 视图的&#x200B;**材料**&#x200B;菜单可让您检查每个场景材料使用的着色器。

<a name="openpbr"></a>

## OpenPBR

Designer默认使用[OpenPBR](https://academysoftwarefoundation.github.io/OpenPBR/)材质模型，它支持多种复杂效果，例如各向异性
传播和朦胧。

Designer中包含的默认[图形模板](../../../compositing-graphs/creating-compositing-gra/creating-a-substance-compositing-graph.md#graph-templates)和[材料示例](../../../compositing-graphs/creating-compositing-gra/creating-a-substance-compositing-graph.md#material-samples)均基于OpenPBR模型。

此着色器的属性遵循[OpenPBR参数引用](https://academysoftwarefoundation.github.io/OpenPBR/#parameterreference)，并且在栅格化程序之间&#x200B;*共享*，
GPU 路径追踪和OpenGL [3D渲染器](../3d-renderers/3d-renderers.md)。

+++ UV

| 参数 | 类型 | 默认值 | 描述 |
|---------------------------------|---------|----------|-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| 平铺 | 浮点 | 1.0 | 一个UV单元格中的纹理重复量，其中较高的值<br/>会导致更多纹理重复。 |
| 基于图形启用物理大小 | 布尔型 | False | 根据图形的[物理尺寸](../../../compositing-graphs/graph-parameters/graph-parameters.md)<br/>自动调整拼贴，以便以适当的比例表示材料。 |
| UV 缩放 | 浮点 2 | 1.0, 1.0 | 按单独的U和V因子调整拼贴的比例，其中<br/>值越高，重复的纹理就越多。 |

+++

+++ 基底

| 参数 | 类型 | 默认值 | 描述 |
|-------------------|--------------|---------------|-------------------------------------------------------------------------------------------------------|
| 直线宽度 | 浮点 | 1.0 | 漫反射与金属基底反射强度的乘数。 |
| 颜色 | float3(RGB) | 0.8, 0.8, 0.8 | 基底反射颜色（涵盖漫反射与金属基底）。 |
| 金属度 | 浮点 | 0.0 | 指定基础材质显示的金属程度。 （将基底从纯电介质调成纯金属） |
| 漫射粗糙度 | 浮点 | 0.0 | 漫反射的粗糙度。 较高的值会使曲面显得较为平整。 |

+++

+++ 镜面

| 参数 | 类型 | 默认值 | 描述 |
|------------|--------------|---------------|----------------------------------------------------------------------------------------------------------------------------------------------------|
| 直线宽度 | 浮点 | 1.0 | 镜面反射率的倍率。 |
| 颜色 | float3(RGB) | 1.0, 1.0, 1.0 | Specular反射的颜色。 （控制金属的物理边缘色调，<br/>和介质的非物理整体色调） |
| 粗糙度 | 浮点 | 0.3 | Specular反射的粗糙度。 数量越少，产生的反射越锐利，<br/>次，数量越多，产生的反射越模糊。 |
| 各向异性 | 浮点 | 0.0 | 金属/介质基底粗糙度的定向偏压，导致沿正切方向的<br/>高光逐渐拉伸。 |
| IOR | 浮点 | 1.5 | 电介质基底的折射率。 |

+++

+++ 透射

| 参数 | 类型 | 默认值 | 描述 |
|------------------|--------------|---------------|-------------------------------------------------------------------------------------------------------------------------------------------------------------|
| 直线宽度 | 浮点 | 0.0 | 透明和不透明介电基底之间的混合物重量。<br/>值越大，材料越透明。 |
| 颜色 | float3(RGB) | 1.0, 1.0, 1.0 | 控制透明基底的颜色，因为表面下有Beer定律体积<br/>吸收。 |
| 深度 | 浮点 | 0.0 | 根据Beer定律，指定光在<br/>完全变成`transmission_color`之前在透明基底中传播的距离。 |
| 散点图 | float3(RGB) | 0.0, 0.0, 0.0 | 控制光线在透明基底内经体积散射后的颜色。 |
| 各向异性 | 浮点 | 0.0 | 透明基底中体积散射<br/>的方向偏差或各向异性量。 |
| 色散比例 | 浮点 | 0.0 | 线性缩放色散量。 |
| 阿贝数 | 浮点 | 20.0 | 介质物理阿贝数，描述介质折射率随波长变化的程度。<br/> |

+++

+++ 次表面散射

| 参数 | 类型 | 默认值 | 描述 |
|--------------|--------------|----------------|--------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| 直线宽度 | 浮点 | 0.0 | 在<br/>漫反射和次表面散射之间调拨不透明介电基底的混合物重量。 |
| 颜色 | float3(RGB) | 0.8, 0.8, 0.8 | 次表面散射介质的可见反射颜色。 |
| 半径 | 浮点 | 1.0 | 次表面散射平均自由程的长度缩放。 |
| 半径比例 | float3(RGB) | 1.0, 0.5, 0.25 | 将RGB乘数乘以subsurface_radius，给出每通道散射<br/>平均自由路径。 |
| 各向异性 | 浮点 | 0.0 | 控制次表面散射的相位函数，其中零<br/>均匀散点光线，正值向前散点，负<br/>值向后散点。 |

+++ 涂层

| 参数 | 类型 | 默认值 | 描述 |
|------------|--------------|---------------|-----------------------------------------------------------------------------------------------------------------------------------------------------|
| 直线宽度 | 浮点 | 0.0 | 在材料上方的反射性透明涂层存在重量。<br/>用于汽车绘画或油性图层等材料。 |
| 颜色 | float3(RGB) | 1.0, 1.0, 1.0 | 透明涂层因吸收作用而呈现的透射色。 |
| 粗糙度 | 浮点 | 0.0 | 透明外套反射的粗糙度。<br/>此值越低，反射越锐利。 |
| 各向异性 | 浮点 | 0.0 | 透明涂层粗糙度的定向偏置，<br/>导致沿涂层正切方向的高光拉伸度增加。 |
| IOR | 浮点 | 1.6 | 透明涂层的折射率。 |
| 变暗 | 浮点 | 1.0 | 调节物理涂层的变暗效果。 |

| 颜色 | float3(RGB) | 1.0, 1.0, 1.0 | 绒毛层的颜色。 |
| 粗糙度 | 浮点 | 0.5 | 绒毛层的粗糙度。 |

+++ 几何

| 参数 | 类型 | 默认值 | 描述 |
|-------------------|--------------|---------------|---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| 不透明度 | 浮点 | 1.0 | 整体材质的不透明度。 |
| 薄壁 | 布尔型 | False | 如果为true，则曲面是双面的，表示一个无穷薄的壳。<br/>适用于几何形状非常细的对象，如树叶或纸张。 |
| 法线 | float3(RGB) | 0.5, 0.5, 1.0 | 输入表面的几何法线。 |
| 正切 | float3(RGB) | 1.0, 0.5, 0.0 | 输入几何切线。 |
| 涂层法线 | float3(RGB) | 0.5, 0.5, 1.0 | 输入涂层的法线。 |
| 涂层切线 | float3(RGB) | 1.0, 0.5, 0.0 | 输入涂层的几何切线。 |
| 高度 | 浮点 | 0.5 | 法向的位移（或凹凸）量。<br/>当Height等于Height级别时，没有位移。<br/>位移是朝向未受扰动的曲面位置的标量变化，<br/>混合法线曲面。<br/>如果无法或不需要镶嵌位移，<br/>Height可以作为凹凸图实现。 |
| 高度级别 | 浮点 | 0.5 | 对应于无位移的Height值（零级别值）。<br/>Height级别将位移相对于<br/>未移动对象的表面移动（但不会缩放或翻转）。<br/>如果Height级别为0，则所有位移都高于此级别。<br/>如果Height级别为1，则所有位移都位于表面下方，但仍保持<br/>相同的比例和方向。 |
| 高度比例 | 浮点 | 1.0 | 场景空间单位中的位移或凹凸的比例。<br/>比例的大小和方向与Height级别的值无关。 |
| 环境光遮蔽 | 浮点 | 1.0 | 用于调暗被遮挡区域的环境遮蔽映射。<br/>白色(1.0)表示完全照亮，黑色(0.0)表示完全遮蔽。 |

### 与现有图形的兼容性

与Designer中包含的其他模型相比，某些OpenPBR材料属性的使用标识符有所不同。
Designer会自动匹配某些标识符，以确保其默认模型与OpenPBR兼容。

+++ 旧版到OpenPBR的使用映射

| 旧版 | OpenPBR |
|-------------------------|-----------------------------|
| 金属 | 金属性 |
| specularEdgeColor | specularColor |
| 粗糙度 | 镜面粗糙度 |
| inisotropicelevel | 镜面粗糙度各向异性 |
| IOR | 镜面反光强度 |
| absorptionColor | transmissionColor |
| subscriptionDistance | transmissionDepth |
| translucency | subsurfaceIght |
| scatteringColor | subsurfaceColor |
| scatteringDistance | 子曲面半径 |
| scatteringDistanceScale | subsurfaceRadiusScale |
| 涂层不透明度 | coatWeight |
| 光泽不透明度 | fuzzWeight |
| sheencolor | fuzzColor |
| 光泽粗糙度 | fuzzRoughness |
| 自发光 | emissionColor |

## Adobe 标准材质

Adobe标准素材(ASM)模型是在Designer 11.2中引入的，并且是Designer的默认着色器
最高版本15.1。

虽然Designer已移至OpenPBR作为新的默认模型，但仍包含ASM，并且其属性也处于共享状态
跨光栅器、GPU 路径追踪和OpenGL [3D渲染器](../3d-renderers/3d-renderers.md)。

[此处](https://experienceleague.adobe.com/en/docs/substance-3d/general-knowledge/asm/adobe-standard-material)记录了该模型。

<a name="usdpreviewsurface"></a>

## UsdPreviewSurface

UsdPreviewSurface模型的目的是预览具有基本特征集的材料，以提高兼容性
跨包括USD和/或Hydra的渲染器。

在Designer中，此材质模型仅受光栅器和GPU 路径追踪[3D渲染器](../3d-renderers/3d-renderers.md)支持。

[此处](https://openusd.org/dev/spec_usdpreviewsurface.html)记录了该模型。
