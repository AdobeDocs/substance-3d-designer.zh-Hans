# MDL学习资源

此页面提供了有关在Substance 3D Designer中使用[MDL图表](../../mdl-graphs/mdl-graphs.md)的学习资源。

## 参考

以下是一组有用的文档和参考，可帮助您进一步了解MDL素材及其在渲染引擎（例如NVIDIA自己的Iray路径跟踪器）中的用法。

* [NVIDIA — 材质定义语言](http://www.nvidia.com/object/material-definition-language.html)
* [NVIDIA - MDL文档](https://raytracing-docs.nvidia.com/mdl/index.html)
* [NVIDIA - MDL手册](http://mdlhandbook.com/)
* [NVIDIA - MDL规范v1.6](https://developer.download.nvidia.com/designworks/mdl-sdk/secure/MDL_spec_1.6.1_16Dec2019.pdf?__token__=exp=1776166178~hmac=38656bc9d8199764568d1fa0d4d945b90c57638ebd37b100a402bdc983e518ee&t=eyJscyI6ImdzZW8iLCJsc2QiOiJodHRwczovL3d3dy5nb29nbGUuY29tLyJ9)

### 在Substance 3D Designer中创建MDL
