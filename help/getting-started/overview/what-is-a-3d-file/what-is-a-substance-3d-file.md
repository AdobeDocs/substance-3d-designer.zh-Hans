# 什么是Substance 3D文件？

![参数化砖墙材料](../../../assets/MaterialsOverview.gif "参数化砖墙材料")

*由Kay Vriend制作的砖墙材料示例。\
可以更改参数以动态控制素材的外观。*

Substance 3D文件是动态纹理生成器，可直接用于多种应用程序。

它是动态的，因为与传统位图文件相反，Substance 3D文件的创建者可以选择<b>公开参数</b>，以便提供<b>将要生成的最终结果的控制</b>。

例如，可以更改物体上的Dust量或足球队球衣的颜色。 你的才能和想象力是你能做的唯一限制。

可以发布Substance素材，然后在集成<b>Substance 3D引擎</b>（如&#x200B;*Unity*&#x200B;或&#x200B;*Unreal Engine*）的<b>外部应用程序</b>中使用。

Substance 3D素材可为&#x200B;*100%程序化*，因此其输出大小将非常小。
