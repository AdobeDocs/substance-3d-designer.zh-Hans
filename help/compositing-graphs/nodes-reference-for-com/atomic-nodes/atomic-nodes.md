# 原子节点

## 放置原子节点

有多种方法可在Substance图中创建原子节点：

### <b>节点调板</b>

![](atomic-nodes.resources/atomic-bar.png)

该节点调板位于[“图形视图”工具栏](../../../interface/the-graph-view/the-graph-view.md)中，便于访问原子节点：只需单击一个节点或在图表中拖动它。

使用此按钮切换调色板： ![](atomic-nodes.resources/node-palette-toggle.png)

### <b>节点菜单</b>

按图形视图中的&#x200B;*空格键*&#x200B;或&#x200B;*Tab*&#x200B;可显示节点的可搜索列表，并默认列出所有原子节点。

通过搜索字段，您可以浏览[库中的所有其他节点](../../../compositing-graphs/nodes-reference-for-com/node-library/node-library.md)，包括[您自己的内容](../../../interface/the-library/managing-custom-content/managing-custom-content-and-filters.md)（如果已添加）。

### <b>图形上下文菜单</b>

右键单击图形并转到“添加节点”子菜单以访问原子节点列表。

### <b>库</b>

[库](../../../interface/the-library/the-library.md)的“原子节点”类别承载所有原子节点。 可以将它们拖放到Substance图中。

### <b>键盘快捷键</b>

您可以定义[自己的键盘快捷键](../../../interface/preferences-window/preferences-window.md)以立即在图表中创建任何节点，包括原子节点。
