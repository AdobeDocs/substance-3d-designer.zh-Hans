# Substance 图形的节点引用

由于Substance 3D Designer是基于节点的纹理软件，因此您可以自由使用许多不同的节点。 本节旨在说明软件的不同类型，并记录软件随附的所有节点。

SD内部称为“节点”，可分为2个main组：

* [原子节点](../../compositing-graphs/nodes-reference-for-com/atomic-nodes/atomic-nodes.md)，任意图表的核心构建块。
* [图形实例](../../compositing-graphs/creating-compositing-gra/graph-instances-sub-gra/graph-instances-sub-graphs.md)，复合节点，[节点库](../../compositing-graphs/nodes-reference-for-com/node-library/node-library.md)中提供了大量预制内容
