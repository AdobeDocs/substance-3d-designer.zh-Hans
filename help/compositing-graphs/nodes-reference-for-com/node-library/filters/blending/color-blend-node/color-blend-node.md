## 描述

执行“颜色”混合模式，该模式可在采用前景色相和色度的同时保留背景的明亮度。

## 参数

### 输入

* **前景**： *颜色输入*
* **背景**： *颜色输入*
* **蒙版**： *灰度输入*\
  用于遮盖节点效果的遮罩槽。

### 参数

* **不透明度**： *0.0 - 1.0*\
  在前景和背景之间混合不透明度。
* **Alpha 值混合处理**： *False/True*\
  切换前景和背景Alpha通道的混合。 如果设置为False，则会忽略前景的Alpha通道。
