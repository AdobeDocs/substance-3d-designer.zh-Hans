## 描述

执行亮度混合模式，以便在采用前景明亮度时保留背景的色相和色度。

## 参数

### 输入

* **前景**： *颜色输入*
* **背景**： *颜色输入*
* **蒙版**： *灰度输入*\
  用于遮盖节点效果的遮罩槽。

### 参数

* **不透明度**： *0.0 - 1.0*\
  在前景和背景之间混合不透明度。
* **Alpha 值混合处理**： *False/True*\
  切换前景颜色和背景Alpha 通道的混合。 如果设置为False，则忽略前景的Alpha 通道。
