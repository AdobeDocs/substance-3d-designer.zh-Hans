## 描述

将单独的灰度输入打包到四个声道中的每一个声道中。 不要与“RGBA合并”混淆，因为此节点可提供更多的合并控制！

一起进行声道打包映射非常有用。 例如可以用于将Smoothness、金属和AO打包到各自的R、G和B信道中。
