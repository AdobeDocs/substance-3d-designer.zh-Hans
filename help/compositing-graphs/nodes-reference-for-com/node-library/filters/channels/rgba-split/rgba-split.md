## 描述

将输入图像拆分为相应的红色、绿色、蓝色和Alpha通道。 有效“解包”图像。

有助于单独分析和使用打包通道。 当使用烘焙的位置图或烘焙的世界空间范本图进行Substance Painter效果时，例如，它可以让您挑出X、Y或Z分量。
