## 描述

将Alpha 通道添加到输入中而不添加Alpha 通道。 不要与[RGBA合并](../../../../../../compositing-graphs/nodes-reference-for-com/node-library/filters/channels/rgba-merge/rgba-merge.md)混淆，此节点更为简单，仅添加Alpha！

当您只是想要遮盖某些内容或您的结果需要Alpha时，可以使用简单但方便的节点。

## 参数

### 输入

* **RGB**： *颜色输入*\
  不含Alpha的彩色图像
* **A**： *灰度输入*\
  用作结果的Alpha的灰度图像。

*无参数。*
