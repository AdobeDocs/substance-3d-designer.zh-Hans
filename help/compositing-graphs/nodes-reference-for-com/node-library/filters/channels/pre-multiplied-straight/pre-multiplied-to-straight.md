## 描述

从Alpha混合边缘的RGB中移除预乘颜色。 有效“取消预乘”背景色，但在此过程中会去除Alpha通道。

这样可消除有时在带有Alpha通道的图像边缘出现的条纹效果。

## 参数

*无参数。*
