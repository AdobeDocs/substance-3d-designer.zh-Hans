## 参数

|  |  |
|:---|:---|
| <b>量化红色通道</b> *整数* | 设置以红色通道为近似依据的步骤数。 |
| <b>量化绿色通道</b> *整数* | 设置用来逼近绿色通道的步骤数。 |
| <b>量化蓝色通道</b> *整数* | 设置用来逼近蓝色通道的步骤数。 |
| <b>量化Alpha通道</b> *整数* | 设置用来逼近Alpha 通道的步骤数。 |
