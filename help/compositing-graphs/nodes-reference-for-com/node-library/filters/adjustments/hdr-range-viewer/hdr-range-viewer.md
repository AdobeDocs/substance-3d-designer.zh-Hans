## 描述

使用“Debug Tool”（调试工具）检查高动态范围的确切区域 颜色版本和灰度版本都存在。

## 参数

* **范围最小值**： *-2.0 - 0.0*&#x200B;开始突出显示的最小范围。
* **范围最大值**： *1.0 - 3.0*&#x200B;最大范围，最多可突出显示。
