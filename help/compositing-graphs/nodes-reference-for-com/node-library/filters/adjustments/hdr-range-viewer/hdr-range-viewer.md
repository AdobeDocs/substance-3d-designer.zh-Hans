## 参数

|  |  |
|:---|:---|
| <b>范围最小值</b> <i>-2.0 - 0.0</i> | 开始高亮显示的最小范围。 |
| <b>范围最大值</b> <i>1.0 - 3.0</i> | 最大范围：最多可高亮显示。 |
