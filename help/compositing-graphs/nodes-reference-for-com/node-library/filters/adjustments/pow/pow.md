## 描述

按指定指数对输入进行通电。 与调整[色阶](../../../../../../compositing-graphs/nodes-reference-for-com/atomic-nodes/levels/levels.md)中点类似，但位于更简单的包中。 当您要执行精确的数学幂运算时，也很有用。

重要提示：根据您输入的是颜色还是灰度，确保使用正确的版本！

## 参数

* **指数**： *0.0 - 10.0*&#x200B;为输入供电的指数。
