## 描述

允许您混合、交换和混合RGB声道。 可用于切换周围的通道，进行更准确的灰度转换和各种类型的打包。

</td>

<a name="parameters"></a>

## 参数

|  |  |
|:---|:---|
| <b>红色通道</b> <i>-200.0 - 200.0</i> | 确定有多少输入RGB声道进入输出红色声道。 |
| <b>绿色通道</b> <i>-200.0 - 200.0</i> | 确定有多少输入RGB声道进入输出绿色声道。 |
| <b>蓝色通道</b> <i>-200.0 - 200.0</i> | 确定有多少输入RGB声道进入输出蓝色声道。 |
| <b>单色</b> <i>False/True</i> | 输出为单色。 允许更精确的灰度转换。 |
