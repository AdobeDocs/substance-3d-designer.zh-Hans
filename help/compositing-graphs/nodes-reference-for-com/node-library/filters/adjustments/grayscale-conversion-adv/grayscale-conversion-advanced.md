## 描述

高级、快速灰度转换节点，提供了一些预设转换模式。

## 参数

* **灰度类型**：*去除饱和度、亮度、平均值、最大值、最小值*&#x200B;去除饱和度将饱和度值设置为0，亮度使用正式的明亮度粗细，平均值与原子节点相同，而“最大值”和“最小值”将分别为每个通道使用最亮值。
