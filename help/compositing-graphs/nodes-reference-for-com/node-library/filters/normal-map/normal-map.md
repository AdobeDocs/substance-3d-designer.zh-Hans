# 法线图

此类别仅包含用于处理和使用Normalmaps的节点。 当希望范数映射处理在数学上正确时，它们是绝对必需的，以避免任何切线空间问题。

使用左侧的<b>导航列表</b>浏览“法线图”下的所有节点。
