## 描述

允许您反转正常映射的任何和所有通道，提供手动执行此操作快速而简单的快捷键。

请记住，对于DirectX或OpenGL样式正常映射，几乎每个使用正常映射作为输入或输出的节点都有一个可以反转绿色通道的选项。 这意味着，对于这些情况，几乎永远不需要此节点。

## 参数

* **反相红色**： *False/True*
* **反转绿色**： *False/True*
* **反转蓝色**： *False/True*
* **反转Alpha**： *False/True*
