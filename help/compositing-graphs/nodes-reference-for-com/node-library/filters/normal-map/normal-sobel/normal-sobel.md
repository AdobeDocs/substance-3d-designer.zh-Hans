## 描述

将Heightmap输入转换为正常映射输出。 此节点是[正常原子节点](../../../../../../compositing-graphs/nodes-reference-for-com/atomic-nodes/normal/normal.md)的一个稍微更高级的版本，它使用Sobel采样而不是标准采样方法。

## 参数

* **强度**： *0.0 - 3.0*&#x200B;转换法线的强度。
* **普通格式**： *OpenGL，DirectX*\
  在不同正常映射格式之间切换（反转绿色通道）。
