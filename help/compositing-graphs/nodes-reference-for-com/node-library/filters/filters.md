# 滤镜

滤镜是处理输入以创建修改后的“滤镜”输出的节点，您可以使用这种方式，从其他知名映像应用程序创建滤镜。 [素材滤镜](../../../../compositing-graphs/nodes-reference-for-com/node-library/material-filters/material-filters.md)的最大区别在于，它们只处理一个（有时是更多）不代表完整素材的输入。

滤镜是最常用的主要类别之一。 除了[原子节点](../../../../compositing-graphs/nodes-reference-for-com/atomic-nodes/atomic-nodes.md)类别之外，其他类别在从头构建纹理时没有这么有用。 请花时间了解每个子类别：

* [调整](../../../../compositing-graphs/nodes-reference-for-com/node-library/filters/adjustments/adjustments.md)\
  扩展的颜色、色调和值调整。
* [混合](../../../../compositing-graphs/nodes-reference-for-com/node-library/filters/blending/blending.md)\
  高级混合模式和扩展混合模式。
* [模糊](../../../../compositing-graphs/nodes-reference-for-com/node-library/filters/blurs/blurs.md)\
  高级、高质量的模糊。
* [频道](../../../../compositing-graphs/nodes-reference-for-com/node-library/filters/channels/channels.md)\
  扩展的通道混合节点。
* [效果](../../../../compositing-graphs/nodes-reference-for-com/node-library/filters/effects/effects.md)\
  纹理导向的图像效果，以及“图层样式”类型的效果。
* [法线图](../../../../compositing-graphs/nodes-reference-for-com/node-library/filters/normal-map/normal-map.md)\
  聚焦法线图的操作。
* [拼贴](../../../../compositing-graphs/nodes-reference-for-com/node-library/filters/tiling/tiling.md)\
  侧重于修复和改进拼贴的节点。
* [变换](../../../../compositing-graphs/nodes-reference-for-com/node-library/filters/transforms/transforms.md)\
  高级（数学）2D空间变换操作。
