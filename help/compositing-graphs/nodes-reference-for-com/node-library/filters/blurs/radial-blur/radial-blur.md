## 参数

|  |  |
|:---|:---|
| <b>示例</b> <i>1 - 128</i> | 设置模糊效果的质量。 |
| <b>角度</b> <i>0.0 - 0.5</i> | 设置效果的“旋转”量。 |
| <b>中心位置</b> | 设置效果的中心点。 |
