# 模糊

“模糊”类别在[标准原子框模糊节点](../../../../../compositing-graphs/nodes-reference-for-com/atomic-nodes/blur/blur.md)上展开。 它包含更多高级、更高品质的模糊，具有多种用途。

请记住，每个“图库模糊”节点都有灰度和颜色版本。 尝试使用适合您输入的版本！

需要了解一些不错的模糊效果：

* [模糊 HQ](../../../../../compositing-graphs/nodes-reference-for-com/node-library/filters/blurs/blur-hq/blur-hq.md)
* [斜率模糊](../../../../../compositing-graphs/nodes-reference-for-com/node-library/filters/blurs/slope-blur/slope-blur.md)
