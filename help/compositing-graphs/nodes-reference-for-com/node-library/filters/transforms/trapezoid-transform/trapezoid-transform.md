## 描述

以透视/梯形变形方式修改输入的特殊变换节点。 具有对顶部和底部拉伸的控制。 价值可以超越极限，产生更强烈的效果。

## 参数

* **顶部拉伸**： *0.0 - 1.0*&#x200B;设置顶部的拉伸或挤压量。
* **底部拉伸**： *0.0 - 1.0*&#x200B;设置底部的拉伸量或挤压量。
* **背景颜色**： *（灰度/颜色值）*\
  设置纯背景色，以防拼贴关闭。
* **采样**： *双线性，最接近*&#x200B;设置采样质量。
