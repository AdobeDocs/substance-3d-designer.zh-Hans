## 描述

将输入图像从选定一侧镜像到选定轴上。 一种非常有用且快速获得对称效果的方法。

## 参数

* **模式**： *镜像轴X、镜像轴Y、镜像* *转角*&#x200B;选择镜像左右或上下或两者。
* **轴X偏移**： *0.0 - 1.0*&#x200B;仅在选择“轴X”时使用，请定义偏移。
* **轴Y偏移**： *0.0 - 1.0*&#x200B;仅在选择“轴Y”时使用，请定义偏移。
* **反转轴X**： *False/True*&#x200B;仅在选择“轴X”时使用，请翻转方向。
* **反转Y轴**： *False/True*&#x200B;仅在选择Y轴时使用，请反向方向。
* **边角类型**： *左上、右上、左下、右下*&#x200B;仅在选择边角类型时使用，请定义镜像的边角。
