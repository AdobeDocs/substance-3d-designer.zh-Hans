## 描述

从[Flood Fill](../../../../../../compositing-graphs/nodes-reference-for-com/node-library/filters/effects/flood-fill/flood-fill.md)基生成灰度图，其值绑定到每个拼贴的单个大小。

值相对于画布总体大小（全白拼贴表示它拉伸整个画布），因此对比度通常较低。
