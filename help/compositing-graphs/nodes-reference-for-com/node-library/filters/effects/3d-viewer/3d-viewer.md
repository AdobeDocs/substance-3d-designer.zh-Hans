## 描述

使用自定义的相机和环境光为指定的SDF或函数图形定义的交叉场景计算3D渲染。<br><br>此节点可用于创作和可视化要在[形状飞溅v2](../../../texture-generators/patterns/shape-splatter-v2/shape-splatter-v2.md)节点中使用的[SDF 函数](../../../../../../function-graphs/nodes-reference-for-fun/function-node-library/function-node-library.md#sdf-functions)。<br><br>帮助程序可用于可视化空间中形状的关键属性。<br><br>对于高级用户，可以创作自定义功能以设置相机和/或每个像素的3D渲染。

> 
> 要了解有关涉及SDF 函数的概念和工作流的更多信息，请转到专用页面： [使用SDF 函数](../../../../../../function-graphs/nodes-reference-for-fun/function-node-library/function-nodes-sdf-functions/working-with-sdf-functions.md)

<a name="inputs"></a>

## 输入

|                            |                                                                                                                                                                                                                                                                                                                                                                                                                                                        |
|:---------------------------|:-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| <b>环境</b> *颜色* | 应投影到作为场景环境且用于环境光照的无限球面上的图像。<br><br>投影为<i>等量矩形</i>，与图库的<b>3D视图> HDRI环境</b>类别中可用的Designer默认环境地图使用的投影相同。<br><br>保持未连接时，将使用默认环境。<br><br><i>提示：</i>使用HDR图像（32位）实现精确光照。 |
| <b>输入1</b> *颜色* | 当<b>输出</b>参数设置为“自定义”时，可以在<b>自定义输出</b>函数图表中取样的图像。<br><br>使用设置为“图像输入0”的[取样颜色](../../../../../../function-graphs/nodes-reference-for-fun/atomic-function-nodes/sampler-nodes/sampler-nodes.md)节点从此图像中取样。 |
| <b>输入2</b> *颜色* | 当<b>输出</b>参数设置为“自定义”时，可以在<b>自定义输出</b>函数图表中取样的图像。<br><br>使用设置为“图像输入1”的[取样颜色](../../../../../../function-graphs/nodes-reference-for-fun/atomic-function-nodes/sampler-nodes/sampler-nodes.md)节点从此图像中取样。 |

<a name="outputs"></a>

## 输出

|               |                                                                                                                                                                                                                                    |
|:--------------|:-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| <b>输出</b> | 使用在<b>输出</b>参数中选择的AOV渲染的场景。<br><br><i>注意：</i>要准确读取某些AOV，请确保2D视图使用线性色彩空间，并且节点使用HDR 32位输出格式。 |

<a name="parameters"></a>

## 参数

|                                               |                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                             |
|:----------------------------------------------|:----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| <b>场景类型</b> *整数* | 用于描述要渲染的曲面和形状的函数类型： <br>- <b>SDF： </b>使用可描述复杂形状的带符号距离字段(SDF)函数。<br>- <b>交集： </b>使用交集函数，当只需要简单的基本形状时，这种速度更快。 |
| <b>SDF场景</b> *浮动* | 描述场景中的表面和形状的符号距离字段(SDF)函数。<br><br>使用库的[SDF 函数](../../../../../../function-graphs/nodes-reference-for-fun/function-node-library/function-node-library.md#sdf-functions)类别中的节点来创作函数。 |
| <b>与场景相交</b> *浮动* | 描述场景中的表面和形状的交叉函数。<br><br>简单基元和运算符的交叉函数在<b>3d_functions.sbs</b>库包的<b>3d_intersection</b>文件夹中可用。<br><br><i>提示：</i>可通过将库中的任何SDF节点放到资源管理器中来访问该包。 |
| <b>输出</b> *整数* | 应由节点输出的3D渲染类型，通常称为AOV（任意输出变量）。<br><br>可用的AOV包括：<br>-<b>美观：</b>3D渲染的最终结果，具有艺术导向的颜色和效果。<br>-<b>正常WS：</b>场景中形状的世界空间法线。<br>-<b>正常TS：</b>场景中形状的切线空间法线。<br>-<b>位置：</b>位置：场景中形状表面的世界空间位置。<br>- <b>距离：</b>从相机到场景中形状的原始距离<br>- <b>深度：</b>形状与相机目标平面的符号距离，平面始终面向相机。<br>- <b>颜色：</b>形状的基色（使用“设置颜色”节点为场景函数中的形状指定颜色）<br>- <b>材质ID：</b>材质ID应用于形状表面（使用“设置材质ID”节点将材质ID分配给场景功能中的形状）<br>- <b>球面跟踪步骤：</b>定义形状表面所需步骤数量的可视化效果。 值越亮，意味着需要更多步骤。<br>- <b>自定义：</b>编写自定义函数以计算每个像素的渲染颜色。<br><br><i>注意：</i>对于某些AOV中的准确读取，请确保2D视图使用线性色彩空间，并且节点使用HDR 32位输出格式。 |
| <b>自定义输出</b> *浮点4* | 函数图形，将渲染场景的每像素RGBA颜色定义为Float4值。<br><br>可用变量：<br>- <code>scene.position</code> (Float3)场景表面的世界空间位置。<br>- <code>scene.normal</code> (Float3)场景表面的世界空间法线。<br>- <code>scene.hit</code> （布尔值）当曲面被摄像机光线照射时，返回“True”。<br>- <code>view.origin</code> （浮点3）相机视图的每像素世界空间位置。<br>- <code>view.direction</code> （浮点3）根据投影模式得出的相机视图的每像素前向矢量。 (E.g. 透视或正交)<br>- <code>material.color</code> (Float3)场景表面的基色。<br>- <code>material.metalness</code> （浮动）场景表面的金属度。<br>- <code>material.roughness</code> （浮动）场景表面的粗糙度。<br>- <code>material.id</code> （整数）场景表面的材质ID。<br><br>可以通过选择以下[示例颜色](../../../../../../function-graphs/nodes-reference-for-fun/atomic-function-nodes/sampler-nodes/sampler-nodes.md)节点插槽对节点的图像输入进行采样：<br>- <b>图像输入0</b>示例输入1.<br>- <b>图像输入1</b>示例输入2。 |
| <b>环境旋转</b> *浮动* | <b>环境</b>的轮转次数。 |
| <b>背景模式</b> *整数* | 指定场景背景的源，该背景绘制在没有形状表面可见的地方。<br><br>- <b>颜色： </b>平坦的“背景颜色”。<br>- <b>环境：</b>提供给“环境”输入的图像，使用等距柱状投影应用到无限球体。  （如果未连接输入，则使用默认环境。） |
| <b>背景颜色</b> *浮点4* | 用作场景背景的纯色。 |
| <b>IBL示例</b> *整数* | 每个相机样本所执行的光照采样量。<br><br>值越高，光照越平滑、越精确，但会降低性能。 |
| <b>相机示例</b> *整数* | 每个像素执行的相机采样量。<br><br>此参数影响消除锯齿的质量和场效应的深度。<br><br>值越大，图像越清晰，杂色越少，但会降低性能。 |
| <b>光线行进步骤</b> *整数* | 用于检测和绘制形状曲面的球面跟踪过程中执行的步骤量。<br><br>值越高，生成的曲面精确且一致（尤其是对于复杂形状），但会降低性能。<br><br><i>提示：</i>将<b>输出</b>参数设置为“球面跟踪步骤”AOV，以可视化需要更多步骤的形状区域。 减少步骤数量将首先影响这些领域。 |
| <b>辅助光线行进步骤</b> *整数* | 在球体追踪过程中执行以计算扩散和遮蔽以绘制投影的步骤量。<br><br>值越高，阴影越精确，但性能会降低。 |
| <b>相机模式</b> *整数* | 将场景投影到渲染图像上的方法： <br><br>- <b>透视： </b>此投影可传递深度并启用镜头效果，如场深度。<br>- <b>正交： </b>此投影拼合场景，使深度无效。<br>- <b>自定义函数： </b>编写函数图表以设置自定义相机。 |
| <b>相机功能</b> *浮点3* | 定义摄像机变换的函数图。 这可用于设置自定义相机。<br><br>函数应<b>设置</b>以下变量：<br>- <code>view.origin</code> （浮点3）相机视图的每像素世界空间位置。<br>- <code>view.direction</code> （浮点3）根据投影模式得出的相机视图的每像素前向矢量。 (E.g. 透视或正交)<br><br>以下变量可用于<b>get</b>：<br>- <code>camera.origin</code> （浮点3）相机的世界空间位置。 (camera.direction * camera_distance + camera.target)<br>- <code>camera.direction</code> （浮点3）相机的世界空间方向，即相机的Y向矢量。<br>- <code>相机。right</code> (Float3)相机的X向右矢量。<br>- <code>camera.up</code> (Float3)相机的Z-up矢量。<br>- <code>camera.target</code> (Float3)摄像机目标的世界空间位置。 |
| <b>UV位置</b> *浮点2* | 2D图像空间中的位置，用于推断围绕<b>目标位置</b>的相机位置和方向。<br><br><i>提示：</i>此参数可以通过在选中节点时使用2D视图中可用的<i>位置Gizmo</i>进行直观调整。 |
| <b>FOV</b> *浮动* | 正交相机的视角(FOV)，它影响缩放系数。 |
| <b>焦距</b> *浮动* | 相机的焦距，影响变焦因子和场效深度。 |
| <b>到目标的距离</b> *浮动* | 相机应与<b>目标位置</b>之间的距离。<br><br>调整此参数可将相机沿相机到目标的方向移动。 |
| <b>目标位置</b> *浮点3* | 相机目标的位置，相机始终朝向该位置。 |
| <b>Tonemapper</b> *整数* | 应用于场景渲染的色调映射算法。<br><br>- <b>无(Raw)<br>- <b>sRGB</b><br>- <b>AgX</b><br>- <b>ACES</b> |
| <b>启用字段深度</b> *布尔值* | 对透视相机模拟“场深度”相机镜头效果。<br><br>使用<b>F值</b>和<b>焦距</b>参数分别调整效果的光圈和焦点。<br><br>结果也受到影响，但影响范围是<b>焦距</b>。 |
| <b>F-number</b> *浮动* | 相机<i>光圈</i>.<br><br>较低的值会使<i>场深度</i>变短，即物体的距离范围变短，随着距离该范围的距离增加，模糊效果更强。 |
| <b>焦距</b> *浮动* | 将焦点的距离设置为沿相机向前矢量与相机之间的距离。<br><br>该距离范围内的曲面将显示为锐化，该范围（即域</i>的<i>深度）由<b>F数</b>定义。 |
| <b>曝光(EV)</b> *浮动* | 到达相机传感器的光量，即渲染中的光照强度。<br><br>较低的值会产生较暗的渲染场景。<br><br>“曝光值”(EV)专门指相机传感器<i>曝光</i>的光线量。 |
| <b>基色</b> *浮点3* | 曲面的缺省基色，该颜色未由其SDF或交集函数定义。 |
| <b>粗糙度</b> *浮动* | 曲面的缺省粗糙度值，其中该值不是由其SDF或相交函数定义的。 |
| <b>金属性</b> *浮动* | 曲面的缺省金属度值，该值不是由其SDF或交集函数定义的。 |
| <b>帮助程序不透明度</b> *浮动* | 3D帮助程序的不透明度，其中较低的值会导致帮助程序变暗。 |
| <b>定界帧</b> *布尔值* | 定义整个场景边界的六边笼子的可视化。 最好是完全包括场景的最小尺寸。<br><br>使用<b>边界帧大小</b>参数调整笼子的大小。<br><br>使用<b>帧外着色</b>参数可让您轻松直观地看到笼子外部的表面，这影响在[形状飞溅v2](../../../texture-generators/patterns/shape-splatter-v2/shape-splatter-v2.md)节点中使用场景的结果。 （请参阅“定界帧大小”工具提示） |
| <b>边框大小</b> *浮点3* | 设置定界帧的XYZ大小。<br><br>将帧调整为适合您的场景，然后将这些相同的值应用于[形状飞溅v2](../../../texture-generators/patterns/shape-splatter-v2/shape-splatter-v2.md)节点的<b>SDF绑定帧大小</b>参数，以确保该节点正确包含和绘制场景中的所有形状。 |
| <b>超帧着色</b> *布尔值* | 将红色应用于边框之外的表面。<br><br>这有助于检查场景是否完全包含在其定界帧中。 |
| <b>轴</b> *布尔值* | 将场景的XYZ轴以从场景原点开始的彩色线条可视化显示。 |
| <b>网格</b> *布尔值* | 在XY轴上放置的网格的可视化，其中X和Y中一个单元的大小是一个场景单位。 |
| <b>变换帮助程序</b> *布尔值* | 上次应用的旋转的可视化。<br><br>可视化包括<br>-<b>表示旋转轴方向矢量的箭头</b>，并在每个世界空间轴的权重之后着色。<br>-<b>表示旋转角度的圆弧</b>，与与其颜色匹配的箭头正交。 |
| <b>SDF等值线</b> *布尔值* | 符号距离场(SDF)函数等值线的彩色可视化。<br><br>等高线是在给定Height上表示XY平面上形状的<i>距离场</i>的规则重复线。<br><br>这对于检查SDF 函数所定义的空间的<i>一致性</i>非常有用。<br><br>使用<b>SDF等值线频率</b>和<b>SDF等值线位置</b>参数调整等值线的密度和Height。 |
| <b>SDF等值线频率</b> *浮动* | 在给定距离内的等值线重复量。<br><br>值越高，线条越密，越细。 |
| <b>SDF等值线位置</b> *浮动* | 用于绘制等高线的XY平面的世界空间Height。<br><br>使用此选项检查形状在不同高度处的距离场。 |
| <b>分钟。 命中距离</b> *浮动* | 定义SDF光线行进过程中转化为命中的最小距离。<br><br>较低的值将增加光线行进步骤的数量。 |
