## 描述

应用基于FXAA算法的消除锯齿滤镜。 您可以使用它来修复形状上的锯齿状像素化边缘。 对于具有像素化边缘的[磁盘形状](../../../../../../compositing-graphs/nodes-reference-for-com/node-library/texture-generators/patterns/shape/shape.md)之类的形状，它特别有用，因为它为消除锯齿边缘提供了一个简单的单节点解决方案。
