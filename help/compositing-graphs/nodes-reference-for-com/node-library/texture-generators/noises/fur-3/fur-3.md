## 描述

这将生成扩散/硬毛刷类型噪声。

## 参数

* **缩放**： *1 - 8*\
  设置效果的全局比例。
* **无序**： *0.0 - 1.0*\
  对噪声进行相移以引入较小的变化。
* **波形量**： *0.0 - 8.0*
* **非正方形扩展**： *False/True*\
  启用以非方形比例补偿挤压和拉伸。
