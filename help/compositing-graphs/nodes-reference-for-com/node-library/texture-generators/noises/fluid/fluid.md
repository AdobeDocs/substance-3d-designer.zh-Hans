## 描述

这是一个有趣的节点，它生成了流动或下降的流体图案。 它是比较复杂的噪声之一，有几个参数。

这种噪声填补了特定的小众市场：它可用于在重力效应下产生雨水、渗漏或任何类型的流体。

## 参数

* **缩放**： *1 - 8*\
  设置效果的全局比例。
* **无序**： *0.0 - 1.0*\
  对噪声进行相移以引入较小的变化。
* **变形强度**： *0.0 - 1.0*
* **图案大小**： *0.0 - 1.0*
* **非正方形扩展**： *False/True*\
  启用压缩补偿并使用非正方形比例拉伸。
