## 描述

**污渍斑点**&#x200B;节点会生成类似于精细飞溅斑点的污渍映射。

</td>

## 参数

* **平衡** *浮动*&#x200B;调整暗值和亮值之间的平衡。
* **对比度** *浮动*&#x200B;调整图像的对比度。
* **反转** *布尔值*&#x200B;使用`1-x`操作反转图像的输出。
* **非正方形扩展***布尔值*&#x200B;启用以非方形比率补偿挤压和拉伸。
* 高级
  * **细节***浮动*&#x200B;调整污点&#x200B;*变形*&#x200B;并分成更细微的污点的数量。
  * **覆盖率** *浮动*&#x200B;调整图像中污点的覆盖率。
  * **覆盖率对比度** *浮动*&#x200B;调整用于控制的&#x200B;*蒙版*&#x200B;的对比度\
    图像中斑点的覆盖范围。
