## 描述

使用稍多一点的angular距离度量生成Worlye Voronoi类型的噪声。 它可用于某些angular和几何目的。

## 参数

* **缩放**： *1 - 256*\
  设置效果的全局比例。
* **无序**： *0.0 - 1.0*\
  对噪声进行相移以引入较小的变化。
* **非正方形扩展**： *False/True*\
  启用以非方形比例补偿挤压和拉伸。
