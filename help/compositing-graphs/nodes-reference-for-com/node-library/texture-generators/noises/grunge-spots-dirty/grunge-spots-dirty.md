## 参数

* **平衡***Float*&#x200B;调整明暗值之间的平衡。
* **对比度***Float*&#x200B;调整图像的对比度。
* **反转** *布尔值*&#x200B;使用`1-x`操作反转图像的输出。
* **非正方形扩展***布尔值*&#x200B;启用压缩补偿并使用非正方形比率拉伸。
* 高级
  * **覆盖范围** *Float*&#x200B;调整Dirt的覆盖范围。
  * **缩放***整数*&#x200B;调整Dirt斑点的缩放。 *较高的*&#x200B;值会产生&#x200B;*更细的*&#x200B;污点。
