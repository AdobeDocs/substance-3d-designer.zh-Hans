## 描述

生成angular的布料折痕状图案。 类似于[折痕噪声](../../../../../../compositing-graphs/nodes-reference-for-com/node-library/texture-generators/noises/creased/creased.md)。

这是一种利基噪声：对于需要此类细节的罕见情况（例如，重新创作细微的大理石图案或布料）非常有用。

## 参数

* **缩放**： *1 - 16*\
  设置效果的全局比例。
* **无序**： *0.0 - 1.0*\
  对噪声进行相移以引入较小的变化。
* **非正方形扩展**： *False/True*\
  启用压缩补偿并使用非正方形比例拉伸。
