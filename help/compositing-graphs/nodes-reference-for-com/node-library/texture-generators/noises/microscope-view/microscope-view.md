## 描述

这会产生扭曲的噪声，看起来像显微镜下的细菌或生物体。

## 参数

* **缩放**： *0 - 10*\
  设置效果的全局比例。
* **变形强度**： *0.0 - 1.0*\
  设置变形效果的强度。 请记住，通过双击并输入–1，也可以输入负值。
* **无序**： *0.0 - 1.0*\
  对噪声进行相移以引入较小的变化
* **非正方形扩展**： *False/True*\
  启用以非方形比例补偿挤压和拉伸。
