## 参数

* **平衡***Float*&#x200B;调整明暗值之间的平衡。
* **对比度***Float*&#x200B;调整图像的对比度。
* **反转** *布尔值*&#x200B;使用`1-x`操作反转图像的输出。
* **非正方形扩展***布尔值*&#x200B;启用压缩补偿并使用非正方形比率拉伸。
* 高级
  * **基噪** *Float*&#x200B;调整基纹理的噪声。
  * **Dirt斑点不透明度***Float*&#x200B;调整Dirt斑点的不透明度。
  * **反转Dirt***布尔值*&#x200B;反转Dirt斑点的影响。
  * **Scratches不透明度***Float*&#x200B;调整划痕的不透明度。
  * **锐化***Float*&#x200B;调整应用于图像的锐化效果的强度。
  * **大变化强度***Float*&#x200B;调整应用于基本纹理的大规模（低频率）变化。
