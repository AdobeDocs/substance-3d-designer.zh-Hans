## 描述

这将生成一种直毛类型的噪声。

## 参数

* **缩放**： *1 - 8*\
  设置效果的全局比例。
* **无序**： *0.0 - 1.0*\
  对噪声进行相移以引入较小的变化。
* **非正方形扩展**： *False/True*\
  启用压缩补偿并使用非正方形比例拉伸。
