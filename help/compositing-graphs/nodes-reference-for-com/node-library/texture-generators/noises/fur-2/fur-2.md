## 描述

这将生成一种波浪型的毛皮噪声。

## 参数

* **缩放**： *1 - 8*\
  设置效果的全局比例。
* **波形比例**： *0.0 - 1.0*\
  改变波浪的规模，波浪越大，重复次数越少。
* **波形旋转**： *0.0 - 1.0*\
  让海浪更加扭曲。 该值可能应保持在较低水平，因为结果可能很极端。
* **非正方形扩展**： *False/True*\
  启用压缩补偿并使用非正方形比例拉伸。
