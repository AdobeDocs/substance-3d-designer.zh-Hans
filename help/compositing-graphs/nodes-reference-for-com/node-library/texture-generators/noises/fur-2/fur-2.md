## 参数

|  |  |
|:---|:---|
| <b>缩放</b> <i>1 - 8</i> | 设置效果的全局比例。 |
| <b>波形缩放</b> <i>0.0 - 1.0</i> | 改变波浪的规模，波浪越大，重复次数越少。 |
| <b>波形旋转</b> <i>0.0 - 1.0</i> | 让海浪更加扭曲。 该值可能应保持在较低水平，因为结果可能很极端。 |
| <b>非正方形扩展</b> <i>False/True</i> | 启用以非方形比例补偿挤压和拉伸。 |
