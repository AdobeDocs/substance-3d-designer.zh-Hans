## 参数

|  |  |
|:---|:---|
| <b>旋转</b> <i>0.0 - 1.0</i> | 旋转效果内部计算。 这可以显着改变噪声的视觉外观：距离值1越远，此效果的像素缩放程度就越低，并且引入的可见“波形”就越多。 |
