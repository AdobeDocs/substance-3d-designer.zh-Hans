## 描述

此节点生成布状噪声。 可以将其解释为Heightmap

当需要具有大比例变化的半方向噪声时，“折痕”非常有用。

</td>

<a name="parameters"></a>

## 参数

|  |  |
|:---|:---|
| <b>缩放</b> <i>1 - 8</i> | 设置效果的全局比例。 |
| <b>变形强度</b> <i>0.0 - 128.0</i> | 设置弯曲/变形效果的强度。 |
| <b>无序</b> <i>0.0 - 100.0</i> | 使用于生成杂色的图层略微发生偏移，以引入变化。 |
| <b>非正方形扩展</b> <i>False/True</i> | 启用以非方形比例补偿挤压和拉伸。 |
