## 描述

此节点生成布状噪声。 可以将其解释为Heightmap

当需要具有大比例变化的半方向噪声时，“折痕”非常有用。

## 参数

* **缩放**： *1 - 8*\
  设置效果的全局比例。
* **变形强度**： *0.0 - 128.0*&#x200B;设置弯曲/变形效果的强度。
* **无序**： *0.0 - 100.0*\
  使用于生成杂色的图层略微发生偏移，以引入变化。
* **非正方形扩展**： *False/True*\
  启用以非方形比例补偿挤压和拉伸。
