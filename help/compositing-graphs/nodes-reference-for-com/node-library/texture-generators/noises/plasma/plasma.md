## 描述

这将生成稍有不同的[高斯噪声](../../../../../../compositing-graphs/nodes-reference-for-com/node-library/texture-generators/noises/gaussian-noise/gaussian-noise.md)变体，将较长的深色条纹作为凹谷。 它具有类似的距离比例控制，可保持拼贴。

## 参数

* **缩放**： *1 - 128*\
  设置效果的全局比例。
* **无序**： *0.0 - 1.0*\
  对噪声进行相移以引入较小的变化。
* **非正方形扩展**： *False/True*\
  启用压缩补偿并使用非正方形比例拉伸。
