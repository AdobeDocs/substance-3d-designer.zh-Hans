## 参数

* **平衡***Float*&#x200B;调整明暗值之间的平衡。
* **对比度***Float*&#x200B;调整图像的对比度。
* **反转** *布尔值*&#x200B;使用`1-x`操作反转图像的输出。
* **非正方形扩展***布尔值*&#x200B;启用压缩补偿并使用非正方形比率拉伸。
* 高级
  * **扭曲** *Float*&#x200B;调整图案中的扭曲量。
  * **分割***整数*&#x200B;调整图案中的分割或渐变重复的数量。
  * **波浪***整数*&#x200B;调整图案中的波浪量。
  * **细节***Float*&#x200B;调整较小扭曲的强度。
  * **旋转随机***Float*&#x200B;调整每个波形的旋转随机性。
