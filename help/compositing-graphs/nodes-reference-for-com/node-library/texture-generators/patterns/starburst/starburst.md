## 参数

|  |  |
|:---|:---|
| <b>分支</b> <i>3 - 512</i> | 效果的分支数量。 |
| <b>模糊量</b> <i>0.0 - 32.0</i> | 控制模糊或柔和的总量。 |
| <b>随机性</b> <i>0.0 - 1.0</i> | 设置轴向随机性，绕中心随机旋转分支。 |
| <b>大小最小值</b> <i>0.0 - 1.0</i> | 设置变化的最小大小。 |
| <b>大小最大</b> <i>0.0 - 2.0</i> | 设置最大大小，如果未使用变化，则控制全局缩放。 |
| <b>大小变化</b> <i>0.0 - 1.0</i> | 引入每个分支的随机缩放。 |
| <b>拼贴</b> <i>1 - 16</i> | 设置结果应平铺的次数。 |
