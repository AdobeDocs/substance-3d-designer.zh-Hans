## 描述

使用可用的调整参数生成简单的星爆效果。

## 参数

* **分支**： *3 - 512*&#x200B;效果的分支数量。
* **模糊量**： *0.0 - 32.0*&#x200B;控制模糊或柔和的总量。
* **随机性**： *0.0 - 1.0*&#x200B;设置轴向随机性，围绕中心随机旋转分支。
* **大小最小值**： *0.0 - 1.0*&#x200B;设置变化的最小大小。
* **大小最大值**： *0.0 - 2.0*&#x200B;设置最大大小，在不使用变化的情况下控制全局缩放。
* **大小变化**： *0.0 - 1.0*&#x200B;引入每个分支的随机缩放。
* **拼贴**： *1 - 16*\
  设置结果应平铺的次数。
