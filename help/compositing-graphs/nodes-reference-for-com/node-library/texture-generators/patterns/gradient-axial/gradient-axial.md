# 轴向渐变

<td width="100.00%" style="border: 0;" valign="top">

## 描述

在两个自定义点之间创建灰度渐变过渡。 允许在任何角度创建线性渐变，但请记住，结果并不总是拼贴。

<a name="parameters"></a>

## 参数

|  |  |
|:---|:---|
| <b>点1</b> | 第一个渐变起始点（黑色） |
| <b>点2</b> | 第二个点用于结束渐变（白色） |
| <b>非正方形扩展</b> <i>False/True</i> | 启用使用非方形比率补偿挤压和拉伸。 |
