## 描述

在两个自定义点之间创建灰度渐变过渡。 允许在任何角度创建线性渐变，但请记住，结果并不总是拼贴。

## 参数

### 参数

* **点1**：\
  第一个渐变起始点（黑色）
* **点2**：\
  第二个点用于结束渐变（白色）
* **非正方形扩展**： *False/True*\
  启用使用非方形比率补偿挤压和拉伸。
