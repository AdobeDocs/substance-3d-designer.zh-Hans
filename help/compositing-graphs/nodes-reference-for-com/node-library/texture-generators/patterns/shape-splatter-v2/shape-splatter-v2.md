## 描述

利用在虚拟<b>3D空间</b>中散射的高级功能，并通过位置、旋转、缩放和随机性控件，在背景Height表面上散点形状。<br><br>该节点提供基本的基本3D形状并支持自定义形状，这些形状可以作为<b>图案图像</b>、<b>地图集</b>提供，也可以作为用于复杂自定义3D形状的<b>符号距离字段(SDF)</b>函数提供。<br><br>有几种<b>分布形状的方法</b>可用，包括创作自定义函数以实现完全控制。<br><br>可以使用自定义<b>密度图</b>将形状拉向特定区域。<br><br><i>注意：</i>此节点不能与Substance引擎的CPU版本一起使用，即SSE2 (Windows、Linux)和NEON (macOS)。

## 输入

|                                      |                                                                                                                                                                                                                                                                                                                                                                  |
|:-------------------------------------|:-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| <b>背景Height</b> *灰度* | 形状散布的基础Height图。 每个颜色的Height使用“最大混合”进行组合，其中使用二者中的较高者。<br><br>背景Height对输出Height的贡献由<b>背景输入不透明度</b>参数控制。 |
| <b>密度图</b> *灰度* | 灰度图根据形状的明亮度驱动形状位移，使形状聚集在较亮的区域中。<br><br>形状位移的强度由<b>密度图乘数</b>参数控制。 |

| <b>Height比例图</b> *灰度* | 灰度图，其值用作形状Height的系数。<br><br>地图的贡献由<b>Height比例图乘数</b>参数控制。 |

| <b>模式输入4</b> *灰度* | 当<b>图案类型</b>设置为“图案输入”时，散布的#4图案的Height映射。<br><br><i>提示：</i>使用接近图案散布时可能具有的最大大小的分辨率。 |
| <b>模式输入5</b> *灰度* | 当<b>图案类型</b>设置为“图案输入”时，散布的#5图案的Height映射。<br><br><i>提示：</i>使用接近图案散布时可能具有的最大大小的分辨率。 |
| <b>模式输入6</b> *灰度* | 当<b>图案类型</b>设置为“图案输入”时，散布的#6图案的Height映射。<br><br><i>提示：</i>使用接近图案散布时可能具有的最大大小的分辨率。 |
| <b>模式输入7</b> *灰度* | 当<b>图案类型</b>设置为“图案输入”时，散布的#7图案的Height映射。<br><br><i>提示：</i>使用接近图案散布时可能具有的最大大小的分辨率。 |

## 参数

|                                                   |                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                               |
|:--------------------------------------------------|:--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|

| <b>位置函数</b> *浮点2* | 用于定义形状分布的函数图。<br><br>图形输出形状在图像中的XY规范化位置的Float2值。<br><br>可用变量：<br> - <code>shape.id</code> （浮动）形状的唯一标识符。<br> - <code>形状.amount</code> （浮点）由<b>Amount</b>参数指定的形状数量。 |
| <b>X数量</b> *整数* | 分布网格中的列数。<br><br>即在X轴上生成的形状数。 |
| <b>Y数量</b> *整数* | 分布网格中的行数。<br><br>即在Y轴上生成的形状数。 |
| <b>金额</b> *整数* | 生成的形状的数量。 |
| <b>输出普通格式</b> *整数* | 输出法线图的格式。<br><br>有效地反转绿色通道。<br><br>- <b>DirectX：</b>Y轴指向上。<br>- <b>OpenGL：</b>Y轴指向下。 |
| <b>非方形扩展</b> *布尔值* | 在非方形图像中，保留形状比例并将其生成扩展到图像边界。 |
| <b>形状类型</b> *整数* | 有多种类型的形状可供散布，每种形状都有特定的特征。<br><br><b>SDF 函数</b>是生成描述3D形状表面的有符号距离字段(SDF)的函数图。 这样可实现复杂过程形状的3D散射，这些形状可以动态变化。<br><br><b>基本形状</b>可使用简单的射线/曲面交集函数计算：立方体、球体、圆柱体、平面、圆盘<br><br><b>输入图案</b>是图形提供的图像。 这些图形映射到平面，并且可以<i>凸出</i>为3D形状：<br> — 图像输入：连接到<b>图案输入#</b>输入针脚的图案。<br> -网格图集：打包到与<b>网格图集</b>输入连接的贴图集图像的图案。 |
| <b>网格图集大小</b> *整数2* | 为<b>网格图集</b>图像输入提供的地图集的行和列数。<br><br><i>注意：</i>地图集中的空单元格将导致形状分布出现间隙。 |
| <b>重新计算网格图集正常</b> *布尔值* | 在<i>True</i>时，将忽略提供给<b>网格图集法线</b>图像输入的法线映射，并且将从头开始计算提供给<b>网格图集Height</b>的图案的法线。<br><br>当<i>False</i>时，将按原样使用提供给<b>网格图集法线</b>的法线映射。<br><br><i>注意：</i>根据<b>形状凸出Height</b>调整法线的强度。 |
| <b>普通网格图集</b> *整数* | 为<b>网格图集法线</b>图像输入提供的法线映射的格式。<br><br>有效地反转绿色通道。<br><br>- <b>DirectX：</b>Y轴指向上。<br>- <b>OpenGL：</b>Y轴指向下。 |
| <b>模式输入编号</b> *整数* | 作为输入图像提供的图案数量。<br><br>向节点添加多达<b>个模式输入#</b>个输入图钉。 |
| <b>启用形状凸出</b> *布尔值* | 通过将输入图案解释为Height映射来切换输入图案的凸出，这将导致复杂的程序3D形状。 |
| <b>形状凸出对称</b> *布尔值* | 启用输入图案的向前/向后对称凸出。<br><br>对称轴为凸出的<i>中点</i>，这意味着它的位置可能会随形状的中心点位置而改变。 |
| <b>形状凸出Height</b> *浮动* | 图像空间中的最大凸出距离，其中1是图像的最长侧。<br><br>此距离与<b>形状比例</b>值成比例。 |
| <b>形状凸出示例</b> *整数* | 为绘制输入图案的凸出而执行的样本量。<br><br>数量越大，凸出就越平滑、越清晰，但会损失一些性能。 |
| <b>模式函数</b> *浮动* | 用于计算映射到3D平面SDF的图案的创作Substance函数图。<br><br>这些图案也可以通过使用<b>启用形状凸出</b>进行凸出。 |
| <b>图案SDF 函数</b> *浮动* | Substance函数图用于创建符号距离场(SDF)，用于描述空间中3D对象的表面。<br><br>使用可用的<i>运算符</i>和<i>转换</i>组合多个SDF <i>基元</i>，浏览库中[SDF 函数](../../../../../../function-graphs/nodes-reference-for-fun/function-node-library/function-node-library.md#sdf-functions)的内置集合以创作复杂对象。<br><br>SDF形状是完全程序性的，并且可以动态调整，这样可以使每个散布的形状都是<i>唯一的</i>。<br><br>使用[3D查看器](../../../filters/effects/3d-viewer/3d-viewer.md)节点以可视化方式显示SDF 函数的结果。<br><br><i>注意：</i>若要在SDF 函数中应用随机性，请使用[哈希](../../../../../../function-graphs/nodes-reference-for-fun/function-node-library/function-node-library.md#random)节点，而不是“随机”。 |
| <b>SDF边界帧大小</b> *浮点3* | 定义SDF形状的最大定界框(Bbox)大小，该大小反过来用于计算其2D Bbox。<br><br>形状仅在其2D Bbox的范围内绘制，其余部分会被裁切。 |
| <b>启用抠图</b> *布尔值* | 切换图案修剪，这将忽略低于<b>抠图阈值</b>的所有值。 这样可确保只使用所需的图案轮廓。 |
| <b>抠图阈值</b> *浮动* | 灰度值，图案中的值将在此灰度值以下进行修剪。 即用作图案侧面影像边框的值。 |
| <b>规范化工作流</b> *布尔值* | 打开后，启用形状Height的自动调整，以便在放大或缩小形状时<i>保留其原始比例</i>。<br><br>关闭时，无论形状的原始比例如何，形状的Height均在图像的完整Height范围内表示。<br><br>仍然可以使用<b>Height比例</b>参数手动调整形状的Height。 |
| <b>形状缩放影响Height缩放</b> *布尔值* | 在<i>True</i>时，形状的Height比例会随着其比例的改变而调整以保持其比例。<br><br>在<i>False</i>时，Height比例与形状比例无关，这会导致变形。 |
| <b>Height缩放</b> *浮动* | 形状的Height的乘数，其中1是形状的完整Height，表示为形状标准化Height范围的图像完整Height范围。 （请参阅<b>规范化工作流</b>） |
| <b>随机Height缩放</b> *Float* | 将每个形状的Height随机缩小到指定比例，其中1表示形状的Height可以完全缩小到0。 |
| <b>Height的比例映射乘数</b> *浮动* | 提供的<b>Height比例图</b>的强度，其中1表示将完整映射值乘以形状的Height。 |
| <b>背景输入不透明度</b> *浮动* | 最终高度图中提供的<b>背景Height</b>输入的强度。<br><br>使用“最大混合”将形状的Height和背景组合在一起，其中使用二者中的较高者。 |
| <b>Height偏离背景</b> *浮动* | 应添加到形状Height的背景Height的比例，1表示添加完整的背景Height。<br><br>这可用于使形状“静止”在背景Height上。 |
| <b>遵从背景</b> *Float* | 应用于形状Height的变形强度以匹配每个像素的背景Height，其中1表示完全匹配。<br><br><i>注意：</i>当<b>Height与背景偏移</b> = 0时，此参数不起作用。 |
| <b>平滑背景斜率</b> *浮动* | 应用于背景Height的平滑强度，用于<b>Height偏离背景</b>和<b>遵从背景</b>调整。<br><br>这可以柔化变形频率和Height偏移，这可能比所需的更严重。 |
| <b>Height偏移</b> *浮动* | 添加到形状Height的值，产生直线偏移。<br><br>该值以图像的完整Height范围表示。 |
| <b>Height偏移随机</b> *浮动* | 将随机偏移应用于形状的Height，直到达到指定值。<br><br>该值以图像的完整Height范围表示。 |
| 从ID</b>Height偏移<b> *浮动* | 根据形状在分布中的索引应用到形状Height的偏移，其中偏移从一种形状线性增加到下一个形状，直到指定值。<br><br>可以手动设置超出<code>[0， 1]的值</code> 范围。 |
| <b>偏移映射乘数</b>Height *浮动* | 使用指定因子调整<b>Height偏移映射</b>应用的偏移的强度，其中1表示按原样应用该映射的强度值。<br><br>通过将偏移映射中的值添加到其XY轴位置来偏移整个形状的Height。<br><br>可以手动设置大于<code>[0， 1]的乘数值</code> 范围。 |
| <b>大小模式</b> *整数* | 定义散布形状大小的方法： <br><br>- <b>自动： </b>大小表示为形状单元格大小的系数。<br>- <b>绝对（纹理空间）： </b>大小表示为图像最长边的系数。 |
| <b>保持大小比例</b> *布尔值* | 调整形状的大小，以保持其在非方形网格和图像大小中的原始比例。 |
| <b>形状缩放</b> *浮动* | 形状的大小作为<b>大小模式</b>定义的系数。<br><br><i>注意：</i>使用<b>泊松磁盘</b>分布时，调整形状的大小会导致形状被移动以利用可用空间。 使用<b>形状缩放后泊松</b>参数就地缩放形状。 |
| <b>形状缩放随机</b> *浮动* | 将形状按比例缩小到指定值，其中的1可能导致某些形状一直缩小到零大小。 |
| <b>缩放映射乘数</b> *浮动* | 将<b>形状比例映射</b>中的值乘以形状大小的强度。 |
| <b>形状缩放后泊松</b> *浮动* | 在泊松盘模拟之后应用的比例因子。 |
| <b>形状大小</b> *浮点3* | 用于调整形状大小的每个轴单独缩放因子。 |
| <b>形状大小随机</b> *浮点3* | 将形状按比例缩小<i>/轴</i>，直至指定值，其中1可能导致某些形状一直缩小到零大小。 |
| <b>圆柱半径</b> *浮动* | 散乱圆柱体SDF的半径。 半径表示为<b>大小模式</b>定义的系数。 |
| <b>形状大小</b> *浮点2* | 用于调整形状大小的每个轴单独缩放因子。 |
| <b>形状大小随机</b> *浮点2* | 将形状按比例缩小<i>/轴</i>，直至指定值，其中1可能导致某些形状一直缩小到零大小。 |
| <b>位置随机</b> *浮动* | 将XY轴上的随机偏移应用到指定值，其中1是图像最长一侧的长度。 |
| <b>定位随机乘数</b> *浮点2* | 应用于XY轴上形状的随机偏移的每轴单独因子。 |
| <b>位置分发序列</b> *整数* | 此算法用于在空间中均匀分布形状。 <br><br>- <b>R2</b>：基于黄金比例。 它是快速的，并且无论形状的多少，它都可以提供更均匀、看似随机的分布。<br>- <b>Halton</b>：基于质数。 对于稀疏分布，它提供了很好的结果，但随着形状数量的增加，它变慢，并且可能产生可见线。<br><br>这些算法被称为<i>准随机</i>和<i>低差异</i>，因为它们遵循旨在均匀覆盖空间（低差异）的确定性序列（准随机）。 |
| <b>密度图乘数</b> *浮动* | 应用于形状的偏移系数，以使形状集中在<b>密度图</b>的最亮区域。 |
| <b>沿法线偏移</b> *浮动* | 沿形状正常位置（即其局部Z轴）置换形状。 |
| <b>沿法向随机偏移</b> *浮动* | 将随机位移量添加到形状正常方向。<br><br>随机量可以是正数，也可以是负数（直至指定值），也可以是负数（直至其负数）。 |
| <b>矢量图位移</b> *浮动* | 将<b>矢量映射</b>中的位移值分别添加到形状的XYZ坐标来应用于形状的RGB系数。<br><br>位移表示为图像最长边的系数。<br>例如， RGB值(0.5， 0.5， 0)将使形状沿X和Y轴移动一半大小。<br><br>参数值1.0表示将添加完整值。 |
| <b>矢量位移乘数</b> *浮点3* | 在每个轴上单独调整一个<b>矢量映射位移</b>，其中0.0表示不对该轴应用位移。 |
| <b>全局偏移</b> *浮点2* | </i>后<i>应用于每个形状位置的偏移，会应用任何Height偏移、随机偏移和其他位移。<br><br>这意味着使用此参数移动形状不会修改它们的位置、方向和缩放。 |
| <b>行位置偏移</b> *浮动* | 根据<b>线条位置偏移模式</b>，应用于网格上形状的线条的偏移。 |
| <b>行位置偏移模式</b> *整数* | 将<b>线段位置偏移</b>应用于形状的方法。<br><br><b>All</b>方法应用偏移作为图像最长一侧（即在纹理空间中）的因子。<br>- <b>All - Horizontal：</b>按行索引的因子，逐行逐步水平添加偏移值。<br>- <b>All - Vertical：</b>按列索引的因子，逐列逐步垂直添加偏移值。<br><br><b>五边形</b>方法应用偏移作为形状单元格大小的系数。<br>- <b>五边形 — 水平：</b>每隔一行统一添加偏移值。<br>- <b>五边形 — 垂直：</b>每隔一列统一添加偏移值。 |
| <b>中心点位置（本地）</b> *浮点3* | 调整形状局部空间中轴线的位置，这将影响变换的原点。 （即位置偏移、旋转和缩放）<br><br>例如，调整Z中心点位置以使形状围绕其底部旋转。 |
| <b>3D旋转</b> *浮点3* | 将每轴旋转均匀地应用于所有形状（轮次数）。 |
| <b>3D旋转随机</b> *浮动* | 应用于形状的随机旋转量的系数，一直到指定值（顺时针或逆时针），以轮次为单位。 |
| <b>3D旋转随机乘数</b> *浮点3* | 按每个轴的单独因子调整<b>3D旋转随机</b>应用的随机旋转量。 |
| <b>3D旋转贴图乘数</b> *浮点3* | <b>形状旋转</b>映射中的值添加到每个形状的每轴旋转时的强度，其中1表示添加全部旋转量。 |
| <b>围绕法线旋转</b> *浮动* | 围绕其法线对所有形状均匀应用的旋转量 — 即其局部Z轴 — 轮数。 |
| <b>围绕法向随机旋转</b> *浮动* | 沿顺时针或逆时针方向将随机旋转应用于每个形状及其法线（即其局部Z轴），最多旋转一圈。 |
| <b>斜率轮换</b> *浮动* | 旋转形状以匹配背景在其位置的斜率。<br>即，将等于全局Z-up向量的旋转应用于背景Height的法线。<br><br>此参数是此旋转的系数，其中1表示应用完全旋转。<br><br>此旋转将添加到可能应用于形状的其他旋转。 |
| <b>旋转输入</b>斜率 *整数* | 用于驱动<b>斜率旋转</b>的斜率源。<br><br>- <b>背景：</b>使用背景Height纹理，从该高度图计算的法线是旋转的目标方向。<br>- <b>矢量映射：</b>矢量映射纹理指定的矢量按原样用于旋转的目标方向。</b> |
| <b>矢量映射乘数</b> *浮动* | 围绕<b>矢量图旋转轴</b>指定的轴旋转形状，以匹配<b>矢量图</b>纹理描述的矢量的方向。即，<br>将等于全局X向右矢量的旋转应用于纹理中的矢量。<br><br>此参数是此旋转的系数，其中1表示应用完全旋转。<br><br>此旋转将添加到可能应用于形状的其他旋转。 |
| <b>矢量图旋转轴</b> *整数* | <b>矢量映射</b>指定的旋转应围绕其执行的轴。<br><br>- <b>法线： </b>围绕其法线旋转形状，类似于使用“围绕法线旋转”参数。<br>- <b>Z轴： </b>围绕全局Z轴旋转形状，类似于使用“3D旋转”参数的Z组件。 |
| <b>随机蒙版</b> *浮动* | 在随机序列中隐藏指定比例的形状总数，其中1表示所有形状都隐藏。<br><br>此参数与蒙版映射合并。 （如果使用） |
| <b>蒙版映射阈值</b> *浮动* | 在其下方隐藏形状的<b>蒙版图</b>中的灰度值。<br><br>映射与<b>掩码随机</b>参数组合。 |
| <b>UV 缩放</b> *浮点2* | 形状的UV的每个轴的乘数，其中拼贴随值的增加而增加。 |
| <b>上限UV 缩放</b> *浮点2* | 圆柱体端盖UV的每轴乘数，其中拼贴随值增加。 |
| <b>CapUV模式</b> *整数* | 计算圆柱体端点UV的方法。<br><br>-<b>极坐标：</b>使用极坐标，其中U围绕圆柱体的Z轴增加，V随着圆柱体离圆柱体越远而增加。<br>-<b>平面：</b>使用一个平面投影，其中UV使用端点的定界框（即调整为端点大小的矩形）进行映射 |
| <b>显示形状2D bbox</b> *布尔值* | 叠加图像中形状的外框矩形的可视化效果。 这是绘制形状时所使用的区域。 |
| <b>显示形状3D框</b> *布尔值* | 叠加形状在3D空间中的定界体积的可视化效果。 这是绘制SDF形状和拉伸平面的区域。<br><br>对于SDF形状，此区域与<b>SDF边界帧大小</b>匹配。<br><br>此可视化有助于评估形状的跨度和方向。 |
| <b>显示形状透视</b> *布尔值* | 叠加形状枢轴的可视化效果，将其作为局部XYZ轴矢量的组合。<br><br>此可视化有助于评估形状的方向及其变换的来源。 （即偏移、旋转、缩放） |
