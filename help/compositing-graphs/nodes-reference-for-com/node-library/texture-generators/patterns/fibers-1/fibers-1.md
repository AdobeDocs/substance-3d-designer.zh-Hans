## 描述

简单的纤维状图案。 可在[Substance 3D Designer](https://www.adobe.com/cn/products/substance3d-designer.html)中使用绳子、网格或布料高度图和细节。

## 参数

* **拼贴**： *1 - 16*\
  设置结果应平铺的次数。
* **非正方形扩展**： *False/True*\
  启用以非方形比例补偿挤压和拉伸。
