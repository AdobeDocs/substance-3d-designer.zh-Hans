## 描述

具有细块的简单网格图案。 适合创建Height和细节映射。

## 参数

* **拼贴**： *1 - 16*\
  设置结果应平铺的次数。
* **旋转45度**： *False/True*&#x200B;将结果旋转45度。
* **非正方形扩展**： *False/True*\
  启用以非方形比例补偿挤压和拉伸。
