## 描述

与[轴向渐变](../../../../../../compositing-graphs/nodes-reference-for-com/node-library/texture-generators/patterns/gradient-axial/gradient-axial.md)类似，在两个自定义点之间创建灰度渐变，其中渐变以黑色开始和结束，并在过渡的中心从峰值到白色。 请记住，结果并不总是平铺的。

</td>
</tr>
</table>

<a name="parameters"></a>

## 参数

|  |  |
|:---|:---|
| <b>点1</b> | 第一个渐变起始点（黑色） |
| <b>点2</b> | 第二个点用于结束渐变（白色） |
| <b>非正方形扩展</b> <i>False/True</i> | 启用使用非方形比率补偿挤压和拉伸。 |
