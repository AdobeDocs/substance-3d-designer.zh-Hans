## 描述

对于生成程序化的“Studio”类型的全景图而言，这是一个有用的节点。 可让您置入和修改聚光灯图像，以及设置其HDR属性。 它可以链接在一起用于多个形状。

## 参数

* **形状矩阵**\
  移动或平移描摹结果，可通过与画布直接交互进行修改。
* **形状**： *正方形，磁盘*&#x200B;设置形状类型。
* **形状颜色**： *（颜色值）*设置形状颜色。
* **形状强度**： *0.0 - 100.0*&#x200B;设置形状的HDR强度。
* **形状柔边框**： *0.0 - 1.0*&#x200B;更改形状的边框柔和度。
* **热点强度**： *0.0 - 100.0*&#x200B;设置形状热点的HDR强度。
* **热点大小**： *0.0 - 1.0*&#x200B;更改形状中热点的大小。
* **热点衰减**： *0.0 - 1.0*&#x200B;更改热点的衰减和边缘混合。
* **热点位置**： *0.0 - 1.0*&#x200B;相对于形状移动热点。
* **启用背景**： *False/True*&#x200B;启用纯色填充背景。 请注意，这意味着您无法再通过混合将它们链接在一起。
* **背景颜色**： *（颜色值）*设置背景纯色。
* **启用纹理输入**： *False/True*&#x200B;允许自定义输入而不是预定义的形状类型。
