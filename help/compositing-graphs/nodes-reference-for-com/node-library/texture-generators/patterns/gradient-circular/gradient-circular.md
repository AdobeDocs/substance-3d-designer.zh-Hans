## 描述

创建由两个圆形自定义点定义的灰度渐变过渡。 转型不是从a到b，而是围绕第一点的一场革命，从第二点开始和结束。 请记住，结果永远不会平铺。

## 参数

* **点1**：\
  第一个点围绕渐变旋转，无需居中
* **点2**：\
  渐变的第二个开始和结束点。
* **非正方形扩展**： *False/True*\
  启用使用非方形比率补偿挤压和拉伸。
