# 渐变圆形

<table>
<tr style="border: 0;">
<td width="33.33%" style="border: 0;" valign="top">

<b>进入：</b>纹理生成器>图案

</td>
<td width="100.00%" style="border: 0;" valign="top">

## 描述

创建由两个圆形自定义点定义的灰度渐变过渡。 转型不是从a到b，而是围绕第一点的一场革命，从第二点开始和结束。 请记住，结果永远不会平铺。

</td>
</tr>
</table>

<a name="parameters"></a>

## 参数

|  |  |
|:---|:---|
| <b>点1</b> | 第一个点围绕渐变旋转，无需居中 |
| <b>点2</b> | 渐变的第二个开始和结束点。 |
| <b>非正方形扩展</b> <i>False/True</i> | 启用使用非方形比率补偿挤压和拉伸。 |
