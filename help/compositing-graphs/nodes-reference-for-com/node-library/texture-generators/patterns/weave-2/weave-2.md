## 描述

生成简单的编织图案。 具有随机性控件。 在最大无序度下，这甚至可以用作噪声。

## 参数

* **拼贴**： *1 - 16*\
  设置结果应平铺的次数。
* **无序**： *0.0 - 100.0*\
  在编织物的缝合处混乱以引入变化。
* **旋转45度**： *False/True*&#x200B;旋转到预设角度。
* **非正方形扩展**： *False/True*\
  启用以非方形比例补偿挤压和拉伸。
