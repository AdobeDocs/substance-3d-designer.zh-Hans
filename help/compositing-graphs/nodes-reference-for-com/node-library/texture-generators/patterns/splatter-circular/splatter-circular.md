## 描述

“Scatter Circular”（飞溅圆形）通过各种控件生成基于圆环的图案。 它可以使用预定义形状或自定义输入。 它类似于[Tile Generator](../../../../../../compositing-graphs/nodes-reference-for-com/node-library/texture-generators/patterns/tile-generator/tile-generator.md)，但使用圆形放置而不是网格。

当您希望使用各种随机选项以圆形方式放置形状时，此功能非常有用。

## 参数

### 输入

两个输入均为可选项。

* **图案图像输入1-6**： *灰度输入（颜色输入）*\
  仅限飞溅圆形：自定义图案图像，在“Pattern”参数设置为“Image Input”时使用。
* **背景**： *灰度输入（颜色输入）*

### 参数

* **图案数量**： *1 - 64*\
  环上要放置的图案拼贴数量。
* **图案数量随机**： *0.0 - 1.0*\
  要放置的图案数量的随机化。 最好用于“振铃量”大于1的情况。
* **图案数量随机最小值**： *1 - 10*&#x200B;设置用于随机化的最小图案数量。
* **振铃量**： *1 - 10*\
  设置要填充的环数。 这些环始终位于外环的内部，间距均匀。
* **非正方形扩展**： *False/True*\
  启用以非方形比例补偿挤压和拉伸。
* **图案**
  * **图案**：*图像输入，方形，磁盘，抛物面，铃声，高斯，荆棘，金字塔，砖块，层次，波形，半圆，脊状的圆，新月，胶囊体，锥形*\
    选择要使用的图案形状。
  * **图案输入编号**： *1 - 6*&#x200B;设置要使用的不同图像输入编号。 仅在上面选择了“*图像输入*”时可用。
  * **模式输入分布**： *随机，按模式数，按振铃号*&#x200B;设置选择多个模式输入的方式。 “随机”表示选择一个随机环路，“模式数”表示它们只置入循环序列中，“按环路”表示每个环依次有不同的环路。
  * **图像输入筛选**： *双线性+Mipmaps，双线性，最接近*
  * **特定模式**： *0.0 - 1.0*\
    可以更改选定图案的形状。 该效果取决于所选图案。
  * **对称随机**： *0.0 - 1.0*\
    设置应根据以下行为随机翻转/镜像的拼贴数。
  * **对称随机模式**： *水平+垂直、水平、垂直*&#x200B;确定对称镜像行为。
* **位置**
  * **半径**： *0.0 - 1.0*\
    设置从图案放置中心的半径。
  * **半径随机**： *0.0 - 1.0*&#x200B;随机分布每个图案拼贴的半径。
  * **环形Radius乘数**： *0.0 - 1.0*\
    影响多个环的间距。
  * **角度随机**： *0.0 - 1.0*&#x200B;随机设置每个图案的角度。 数量越高，旋转角度越大。
  * **螺旋因子**： *0.0 - 1.0*\
    将环变成螺旋形，其中每个拼贴都以略微增加的半径放置。
  * **跨页**： *0.0 - 2.0*&#x200B;设置戒指的转动量。 这可以超出其限度。
  * **沿方向**&#x200B;偏移： *0.0 - 1.0*\
    沿每个图案的角度从中心向外移动它们。 此效果在很大程度上取决于“角度随机”，或者它看起来像“半径”的乘数。
  * **全局偏移**： *0.0 - 1.0*\
    平移整个形状。
* **大小**
  * **连接图案**： *False/True*&#x200B;使图案拼贴的长度取决于半径，这意味着每个形状都应接触上一个和下一个形状。
  * **大小（已连接）**： *0.0 - 1.0*\
    全局更改每个图案的大小。 连接后，它相对于总半径。
  * **大小随机**： *0.0 - 1.0*\
    分别随机调整每个图案的大小。
  * **缩放**： *0.0 - 2.0*\
    统一缩放每个图案。
  * **随机缩放**： *0.0 - 1.0*\
    随机均匀缩放。
  * **按图案编号缩放**： *0.0 - 1.0*&#x200B;使图案缩放取决于环上的位置。
  * **反转模式号**： *False/True*\
    与前一个选项结合使用，可以将缩放比例从小调整为大，反之亦然。
  * **按振铃号缩放**： *0.0 - 1.0*&#x200B;使缩放与振铃号相关。
  * **反转环数**： *False/True*&#x200B;与上一个选项结合使用，可将缩放比例从小反转为大，反之亦然。
* **旋转**
  * **图案旋转**： *0.0 - 1.0*&#x200B;统一旋转每个图案。
  * **图案旋转随机**： *0.0 - 1.0*\
    随机化图案旋转。
  * **图案旋转透视**：*中心，X轴最小，X轴最大，Y轴最小，Y轴最大*\
    设置要单独旋转每个图案的透视点位置。
  * **居中方向**： *False/True*\
    旋转每个图案，使其面向圆环中心。 将其转换为会为他们提供相同的方向 — 这可能会在使用“沿方向偏移”时产生不需要的效果。
  * **环旋转**： *0.0 - 1.0*&#x200B;围绕中心旋转整个环。
  * **环旋转随机**： *0.0 - 1.0*&#x200B;随机化每个环的旋转。
  * **环形旋转偏移**： *0.0 - 1.0*\
    偏移每个环的旋转。
* **颜色**
  * **颜色**： *（灰度值）*要与选定图案相乘的颜色。
  * **明亮度随机**： *0.0 - 1.0*&#x200B;每个图案拼贴的随机颜色或明亮度。
  * **按比例明亮度**： *0.0 - 1.0*&#x200B;使明亮度依赖于单个图案比例。
  * **按图案编号列出的明亮度**： *0.0 - 1.0*&#x200B;使明亮度与图案序列相关。 例如，可以与螺旋线一起使用。
  * **反转图案编号**： *False/True*&#x200B;反转上一个选项。
  * **按环号划分的明亮度**： *0.0 - 1.0*&#x200B;使明亮度与环序列相关。
  * **反转振铃号**： *False/True*&#x200B;反转上一个选项。
  * **随机蒙版**： *0.0 - 1.0*&#x200B;随机隐藏图案。
  * **背景颜色**： *（灰度值）*更改纯背景颜色。
  * **混合模式**：*添加、最大、添加子集*&#x200B;设置如何混合重叠图案。
  * **全局不透明度**： *0.0 - 1.0*&#x200B;设置整个结果的全局不透明度。
