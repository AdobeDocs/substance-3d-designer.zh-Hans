# 要遮盖的形状飞溅v2

<table>
<tr style="border: 0;">
<td width="33.33%" style="border: 0;" valign="top">

![形状飞溅v2到蒙版图标](shape-splatter-v2-to-mask.png "形状飞溅v2到蒙版")

<b>进入：</b>生成器>图案

</td>
<td width="100.00%" style="border: 0;" valign="top">

## 描述

从[形状飞溅v2](../shape-splatter-v2/shape-splatter-v2.md)节点生成的一系列形状中计算蒙版。<br><br>可用选项包括随机选择以及按唯一标识符和/或材质ID/图案ID选择形状范围*。<br><br>形状由[形状飞溅v2](../shape-splatter-v2/shape-splatter-v2.md)节点从它们的<i>Height混合</i>与背景Height中预蒙住形状。<br>背景和未选择的形状都是纯黑色。 （即值0）<br><br><b>*：</b>从形状飞溅UVW输入检索到的值之一是材质ID或图案ID，具体取决于形状飞溅v2节点中使用的<b>形状类型</b>：<br>- <i>SDF/primitive</i>：材质ID<br>- <i>图案输入/网格图集：</i>图案ID，即列表/地图集中图案的索引。

</td>
</tr>
</table>

<a name="inputs"></a>

## 输入

|                             |                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                           |
|:----------------------------|:----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| <b>Splatter UVW</b> *颜色* | <b>R</b> — 形状的UV的U分量。<br><b>G</b> — 形状的UV的V分量。<br><b>B</b> — 形状的Height。 (W)<br><b>A</b> — 打包的数据：<br> - <i>整数部分：</i>形状的唯一标识符。 (ID)<br> - <i>分数部分：</i>取决于<b>形状类型</b>：如果是SDF/基元，则为素材ID；如果是pattern input/atlas，则为图案ID*。<br><br><b>*：</b>图案ID是列表/地图集中形状的索引。 |

<a name="outputs"></a>

## 输出

|               |                                           |
|:--------------|:------------------------------------------|
| <b>输出</b> | 所选形状的计算蒙版。 |

<a name="parameters"></a>

## 参数

|                                                         |                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                   |
|:--------------------------------------------------------|:------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| <b>输出</b> *整数* | 在输出蒙版中为选定形状使用的值。<br><br>- <b>二进制蒙版： </b>选定形状都使用值1。<br>- <b>形状ID（整数）： </b>选定形状使用其唯一标识符。 (ID)<br>- <b>材质ID（整数）：</b>所选形状使用其材质ID。<br>- <b>形状ID（规范化）：</b>所选形状使用从最低所选材质ID到最高映射到[0、1]范围的唯一标识符(ID)。<br>- <b>材质ID（规范化）：</b>所选形状使用从最低所选材质ID到最高映射到[0、1]范围的材质ID。 |
| <b>形状ID起始范围</b> *整数* | 用作选择范围开头的形状唯一标识符(ID)。 （已包括） |
| <b>形状ID结束范围</b> *整数* | 用作选择范围末尾的形状唯一标识符(ID)。 （已包括） |
| <b>形状ID偏移</b> *整数* | 在选择范围的上下文中按指定值偏移形状的唯一标识符。<br><br>这样，不必手动调整起始和结束边界，即可轻松将当前选区偏移指定的值。 |
| <b>材质/图案ID蒙版组合</b> *整数* | 已指定用于将按唯一标识符(ID)选择的内容与按素材ID/图案ID选择的内容组合的逻辑运算符。<br><br>- <b>无：</b>请完全忽略选择的素材ID/图案ID。<br>- <b>AND：</b>选定的形状必须同时包含在ID和素材ID/图案ID范围中。 （包含较少的形状）<br>- <b>或：</b>所选形状必须包含在ID范围或素材ID/图案ID范围中。 （包括更多形状） |
| <b>材质/图案ID起始范围</b> *整数* | 用作选取范围起始的材料ID或阵列ID*。 （已包含）<br><br><b>*：</b>有关详细信息，请参阅节点说明。 |
| <b>材质/图案ID结束范围</b> *整数* | 用作选择范围末尾的材料ID或阵列ID*。 （已包含）<br><br><b>*：</b>有关详细信息，请参阅节点说明。 |
| <b>形状随机蒙版</b> *浮动* | 形状随机蒙版的一个因素，其中1表示所有形状都被蒙版。 |
