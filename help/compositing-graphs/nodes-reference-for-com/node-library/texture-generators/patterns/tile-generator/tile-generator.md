## 描述

Tile Generator是库中最高级的节点之一。 如果学会了如何掌握它，您就可以创建任何类型的图案（在一定限制内）。 从2017版2.1开始，进行了一些大的更新，使此节点更符合[平铺Sampler](../../../../../../compositing-graphs/nodes-reference-for-com/node-library/texture-generators/patterns/tile-sampler/tile-sampler.md)的功能。

此节点对于各种场景都非常有用，但请记住，仅仅读取参数并不能完全教您如何使用它们。 我们建议你也试试！

在所有情况下，99%不需要颜色版本！

一些常规使用提示：

* 您可以从基本形状开始，但如果您有自定义输入（将&#x200B;**图案类型**&#x200B;设置为&#x200B;*图像输入*），请先创建它！ 那个决定很多外观。
* 首先正确设置X和Y数量。
* 查找正确的&#x200B;**大小**&#x200B;模式：相对模式（如&#x200B;**间隙**）的行为与&#x200B;**绝对**&#x200B;模式截然不同。
* 接下来，调整全局&#x200B;**缩放**&#x200B;和非一致&#x200B;**大小**。
* 最后，调整任何&#x200B;**“变量”**&#x200B;参数，直到它满足您的需要。 微妙是变化的关键！

## 参数

### 输入

* **图案输入1-6**： *灰度输入*\
  自定义图案图像，在“Pattern”参数设置为“Image Input”时使用。
* **背景**：*灰度输入*&#x200B;要使用的背景，而不是纯色。

### 参数

* **X数量**： *1 - 64*\
  图案的X重复次数。
* **Y数量**： *1 - 64*\
  模式的Y重复次数。
* **非正方形扩展**： *False/True*\
  启用以非方形比例补偿挤压和拉伸。
* **图案**
  * **图案**：*图像输入，方形，圆盘，抛物面，贝尔，高斯，刺，金字塔，砖，渐变，波形，半铃，脊状贝尔，新月，胶囊，锥形体*\
    选择要使用的图案形状。
  * **图案输入编号**： *1 - 6*&#x200B;要使用的不同图像输入数量。 仅在上面选择了“*图像输入*”时可用。
  * **模式输入分布**： *随机，按模式数*&#x200B;如果选择的图像输入超过1，如何在不同的图像输入之间进行选择。
  * **特定模式**： *0.0 - 1.0*\
    可以更改选定图案的形状。 效果取决于选定的图案。
  * **图像输入筛选（仅限引擎>v4）**：*双线性+ Mipmaps，双线性，最接近*
  * **旋转**： *0、90、180、270*&#x200B;以90度的步长以设定的角度全局旋转所有拼贴。
  * **旋转随机**： *0.0 - 1.0*&#x200B;随机会将拼贴旋转4个90度步长之一。
  * **昆昆克斯翻转**： *False/True*&#x200B;每隔拼贴旋转90度。
  * **对称随机**： *0.0 - 1.0*&#x200B;按所选对称随机模式随机镜像某些图案。 此值越高，镜像的图案就越多。
  * **对称随机模式**： *水平+垂直、水平、垂直*&#x200B;确定对称随机大于0时的镜像行为。
* **大小**
  * **&#x200B;**&#x200B;大小模式&#x200B;**：***正常 — 空隙，正常 — 大小，保持比例，绝对，像素*设置图案大小的一般行为。\
    法线 — 间隙允许您定义图案元素之间的间隙。 受X和Y值的影响。\
    “法线 — 大小”允许您定义阵列元素的大小，而不管间隙如何。 受X和Y值的影响。\
    使用“Keep Ratio”（保持比例），可以设置受X和Y量影响的大小，但两者的X和Y比例保持不变。\
    绝对用于设置不受X和Y数量影响的绝对大小。\
    “像素”可用于设置绝对大小（以像素为单位），不受X和Y数量影响。 更改分辨率将会影响元素的大小。
  * **中等大小**： *0.0 - 1.0*&#x200B;以列和行为单位交替更改大小。
  * **空隙X/Y**： *0.0 - 1.0*&#x200B;仅在“正常 — 空隙大小”模式下可用。 更改间隙间隙。 影响形状之间的接缝，从而允许不同于&#x200B;**比例**&#x200B;的非均匀控制。
  * **大小（绝对/像素）**： *0.0 - 1.0*\
    仅在“正常 — 间隙大小”模式之外可用。 设置非一致大小，不同于&#x200B;**缩放**。
  * **比例**： *0.0 - 2.0*&#x200B;设置全局比例。
  * **随机缩放**： *0.0 - 1.0*&#x200B;设置每个拼贴的全局缩放变化。
  * **缩放随机种子**： *0 - 1000*&#x200B;偏移缩放变化种子。
* **位置**
  * **偏移**： *0.0 - 1.0*&#x200B;在每个连续行或列上增量偏移整个图案（行为取决于“垂直偏移”参数）。
  * **随机偏移**： *0.0 - 1.0*&#x200B;随机化行偏移。
  * **偏移随机植入**： *0 - 1000*&#x200B;更改随机偏移效果的相对植入。
  * **垂直偏移**： *False/True*&#x200B;设置偏移效果是在行还是行上发生；水平还是垂直。
  * **位置随机**： *0.0 - 1.0*&#x200B;以非统一方式随机化位置，X和Y分别使用控件。
  * **全局偏移**： *0.0 - 1.0*&#x200B;在X和Y轴上移动整个结果。
* **旋转**
  * **旋转**： *0.0 - 1.0*&#x200B;对所有图案拼贴进行统一的自由旋转。
  * **旋转随机**： *0.0 - 1.0*&#x200B;随机旋转所有拼贴。 此值越高，可以旋转更多的拼贴。
* **颜色**
  * **颜色**： *（灰度值）*设置拼贴纯色。
  * **明亮度/颜色随机**： *0.0 - 1.0*&#x200B;引入每拼贴颜色或明亮度变化。
  * **按数字明亮度**： *False/True*&#x200B;在整个图案上淡化明亮度。
  * **按比例明亮度**： *False/True*&#x200B;使明亮度变化取决于拼贴比例。
  * **检查器蒙版**： *False/True*&#x200B;隐藏所有其他图块。
  * **水平蒙版**： *False/True*&#x200B;隐藏所有其他列。
  * **垂直蒙版**： *False/True*&#x200B;隐藏每隔一行。
  * **随机蒙版**： *0.0 - 1.0*&#x200B;随机隐藏拼贴。 此值越高，拼贴消失得越多。
  * **反转蒙版**： *False/True*&#x200B;反转此部分中的任何蒙版效果的结果。
  * **混合模式**：*添加、最大、添加子集*&#x200B;设置要使用的混合模式。
  * **背景颜色**： *（灰度值）*设置纯背景颜色。
  * **全局不透明度**： *0.0 - 1.0*&#x200B;设置全局拼贴不透明度。
  * **反向渲染顺序**： *False/True*&#x200B;将拼贴渲染为从前到后，反之亦然。
