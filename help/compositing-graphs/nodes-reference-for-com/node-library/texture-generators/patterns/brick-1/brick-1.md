## 描述

简单砖块模式，请参阅[砖块生成器](../../../../../../compositing-graphs/nodes-reference-for-com/node-library/texture-generators/patterns/brick-generator/brick-generator.md)或[Tile Generator](../../../../../../compositing-graphs/nodes-reference-for-com/node-library/texture-generators/patterns/tile-generator/tile-generator.md)了解更多选项。

## 参数

* **拼贴**： *1 - 16*\
  设置结果应平铺的次数。
* **边缘平滑度**： *0.0 - 1.0*&#x200B;粗糙和平滑边缘之间的混合。
* **间隙宽度**： *0.0 - 1.0*&#x200B;设置间隙（间隙大小）。
* **非正方形扩展**： *False/True*\
  启用压缩补偿并使用非正方形比例拉伸。
