## 描述

非常简单的棋盘格图案。 拼贴有意设置为较低值，以使其尽可能通用。

该方法具有明显的对比和拼贴，是一种比较实用的试验方法。

</td>
</tr>

<a name="parameters"></a>

## 参数

|  |  |
|:---|:---|
| <b>拼贴</b> <i>1 - 16</i> | 设置结果应平铺的次数。 |
| <b>旋转45度</b> <i>False/True</i> | 将整个图案旋转45度。 |
| <b>非正方形扩展</b> <i>False/True</i> | 启用以非方形比例补偿挤压和拉伸。 |
