<a name="parameters"></a>

## 参数

|  |  |
|:---|:---|
| <b>拼贴</b> <i>1 - 16</i> | 设置结果应平铺的次数。 |
| <b>边缘Smoothness</b> <i>0.0 - 1.0</i> | 在粗糙和平滑边缘之间混合。 |
| <b>间隙宽度</b> <i>0.0 - 1.0</i> | 设置间隙（间隙大小）。 |
| <b>非正方形扩展</b> <i>False/True</i> | 启用以非方形比例补偿挤压和拉伸。 |
