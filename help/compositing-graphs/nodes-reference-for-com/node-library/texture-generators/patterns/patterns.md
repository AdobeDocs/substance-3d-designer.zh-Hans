# 图案

图案是看起来像是人造的人造图形。 它们大多遵循放置规则，但大多数情况下可引入随机变化。

当您希望将常规图案（如砖块、拼贴、编织图案等）作为基本图案时，它们非常有用。

几乎所有图案都非常完美，并且与分辨率无关，这意味着您可以重新缩放它们而不会损失质量。

使用左侧的<b>导航列表</b>浏览“模式”下的所有节点。
