## 描述

在XY尺寸可调的网格上打包多达16张彩色图像。<br>输出地图集图像可以由[形状飞溅v2](../shape-splatter-v2/shape-splatter-v2.md)或[形状飞溅映射器颜色](../shape-splatter-v2-mapper-color/shape-splatter-v2-mapper-color.md)节点采样。

另请参阅[网格图集灰度](../grid-atlas-grayscale/grid-atlas-grayscale.md)。

<a name="parameters"></a>

## 参数

|                                   |                                                                                                                                                                                                                                                                                                                                                                    |
|:----------------------------------|:-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| <b>网格大小X</b> *整数* | X轴上网格的大小。<br>即，在X轴上填充的图像数。 |
| <b>网格大小Y</b> *整数* | Y轴上网格的大小。<br>即，在Y轴上填充的图像数。 |
| <b>输出大小模式</b> *整数* | 根据节点的“输出大小”基本参数定义输出图像大小的方法： <br><br>- <b>手动： </b>按原样使用大小。<br>- <b>自动比例： </b>根据网格大小调整图像比例，以最小化图像大小。 对于使用3行或列的非方形网格，例如(3,2)、(4,3)，将出现变形 |
