## 描述

使用节点提供的其他数据，将灰度图像映射到使用[形状飞溅v2](../shape-splatter-v2/shape-splatter-v2.md)节点生成和散布的形状上。<br><br>图像可作为单独的图案输入提供或打包到网格图集中，并可使用UV映射、三面投影或自定义映射应用于形状。<br><br>形状可以着色，其明亮度可以根据每个形状均匀或随机调整。

另请参阅[形状飞溅v2映射器颜色](../shape-splatter-v2-mapper-color/shape-splatter-v2-mapper-color.md)。

</td>
</tr>
</table>

>[!INFO]
>
> 此节点需要[形状飞溅v2](../shape-splatter-v2/shape-splatter-v2.md)节点生成的输入数据。
> 
> 形状飞溅v2系列中的其他节点：

>
> 借助[网格图集灰度](../grid-atlas-grayscale/grid-atlas-grayscale.md)节点，您可以将图像打包成自定义大小的图集，最多可在4*4单元格中包含16个图案。

## 参数

|                                            |                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                   |
|:-------------------------------------------|:------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| <b>投影模式</b> *整数* | 将输入图像投影到形状上的方法： <br><br>- <b>从飞溅UV：</b>使用[形状飞溅v2](../shape-splatter-v2/shape-splatter-v2.md)节点提供的UV。<br>- <b>三面图：</b>使用三面投影将图像映射到形状的局部XYZ轴上。<br>- <b>自定义函数：</b>编写函数图形以定义图像到形状的映射。 |
| <b>自定义函数</b> *浮动* | 将形状的每像素明亮度指定为浮点。<br><br>以下变量可用：<br>- <code>shape.position.os</code> (Float3)形状曲面在对象空间中的位置。<br>- <code>shape.position.ws</code> (Float3)形状曲面在世界空间中的位置*.<br>- <code>shape.normal.os</code> (Float3)对象空间中形状曲面的法线。<br> - <code>shape.normal.ws</code> (Float3)形状曲面在世界空间中的法线*.<br>- <code>shape.id</code> （浮动）形状的唯一标识符。<br>- <code>material.id</code> （浮动）形状表面的材质ID，由[形状飞溅v2](../shape-splatter-v2/shape-splatter-v2.md)节点定义。<br><br>*：形状的世界空间位于其轴心且不考虑形状的Height。 这意味着与对象空间的唯一区别是方向。<br><br>如果需要对[形状飞溅v2映射器](shape-splatter-v2-mapper-grayscale.md)节点的输入进行取样，可以使用以下[灰度示例](../../../../../../function-graphs/nodes-reference-for-fun/atomic-function-nodes/sampler-nodes/sampler-nodes.md)节点输入槽：<br>- 0：网格图集<br>- 1-8：图案输入1-8 |
| <b>混合对比度</b> *浮动* | 平面投影之间过渡的锐度，其中1表示无淡化渐变。 |
| <b>图像投影</b> *整数* | 跨平面投影分布的<b>图案输入#</b>图像数量有助于三平面映射。<br><br>为了覆盖形状的所有侧面，在每个轴上执行前(+)和后(-)平面投影，总计6个投影。<br><br>-<b>1张图像：</b>图案输入1用于所有平面投影。<br>-<b>3张图像：</b>单独的图案输入用于每个轴的+/ — 投影。<br>-<b>6张图像：</b>每个投影使用单独的图案输入。<br>-<b>每个材质ID使用1张图像：</b>每个材质ID使用单独的图案输入，其中每个图像用于所有平面投影。 |
| <b>投影中心</b> *浮点3* | 在对象空间中，按轴偏移三面投影。<br><br>此偏移应用于<i>整个投影空间</i>，因此一个轴上的偏移会影响投影在<i>其他两个</i>轴上的纹理的位置。 |
| <b>投影比例</b> *浮动* | 按指定因子调整<i>所有轴</i>上的投影纹理的比例。 |
| <b>输入选择模式</b> *整数* | 选择应映射到形状的输入图像的方法。<br><br>在源[形状飞溅v2](../shape-splatter-v2/shape-splatter-v2.md)节点中选择的<b>形状类型</b>改变了将图像分配给形状的方式：<br><br>-<b>网格图集</b>表示通过匹配的网格索引在“网格图集输入”中获取图像（两个图集应使用相同的网格大小）<br>-<b>模式输入</b>表示通过匹配索引在“模式输入#”输入中获取图像。<br>-<b>其他形状类型：</b>图像是通过将索引与形状的材质ID进行匹配来分配的s.<br><br>选择索引的可用方法是：<br>- <b>从飞溅数据：</b>将“图案输入#”或“网格图集输入”图像的索引与[形状飞溅v2](../shape-splatter-v2/shape-splatter-v2.md)节点分配的形状的索引匹配。<br>- <b>手动：</b>使用“图像索引”参数指定的索引。<br>- <b>随机：</b>在“随机范围”参数指定的范围内使用随机索引。 |
| <b>模式输入编号</b> *整数* | 应映射到形状的<b>图案输入#</b>输入图像的数量。 |
| <b>图像索引</b> *整数* | 应映射到形状的<b>模式输入#</b>或<b>网格图集输入</b>的输入模式的索引。 |
| <b>随机范围</b> *整数2* | 应随机选择来自<b>图案输入#</b>或<b>网格图集输入</b>的索引范围，以便将其映射到形状上。 |
| <b>明亮度调整</b> *Float* | 统一应用于所有形状明亮度的偏移。 |
| <b>明亮度随机</b> *Float* | 应用于形状明亮度的随机正偏移或负偏移，最大为指定值。 |
| <b>颜色输入不透明度</b> *Float* | 根据所选的<b>颜色输入混合模式</b>，<b>颜色输入</b>对形状颜色的贡献的强度。 |
| <b>颜色输入混合模式</b> *整数* | 用于合并前景图像和背景图像的颜色混合操作。<br><br>这些操作与[混合](../../../../atomic-nodes/blend/blend.md)节点中的对应操作相同。<br><br>可用模式：<br>- <b>复制</b><br>- <b>相加（线性减淡）</b><br>- <b>去除</b><br>- <b>相乘</b><br>- <b>叠加</b> |
| <b>拼贴模式</b> *整数* | 应沿其重复纹理的轴： <br> - <b>无拼贴</b><br> - <b>水平拼贴</b><br> - <b>垂直拼贴</b><br> - <b>H和V拼贴</b>：组合水平和垂直拼贴。 |
| <b>拼贴</b> *Float* | 调整映射到形状的图像的全局拼贴<br><br>值越高，重复次数越多。 |
| <b>UV 缩放</b> *Float2* | 使用单独的U和V缩放控件按指定因子调整映射到形状的图像的拼贴。 值越高重复次数越多。 |
| <b>UV 偏移</b> *浮点2* | 将偏移应用于形状上的图像映射，从而能够微调图像在形状上的位置。<br><br>此偏移已添加到<b>随机偏移</b>（如果有）。 |
| <b>随机偏移</b> *浮动* | 将每个形状</i>的随机正偏移量或负偏移量<i>应用于形状间图像的映射，直到达到指定的值。<br><br>此偏移已添加到<b>UV 偏移</b>（如果有）。 |
