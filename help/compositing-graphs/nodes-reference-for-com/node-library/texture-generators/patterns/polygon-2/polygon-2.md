## 描述

生成带有调整选项的平滑渐变多边形形状。 有关更高级的版本，请参阅[多边形1](../../../../../../compositing-graphs/nodes-reference-for-com/node-library/texture-generators/patterns/polygon-1/polygon-1.md)。

## 参数

* **边数**： *3 - 32*&#x200B;边数。
* **比例**： *0.0 - 1.0*&#x200B;设置全局比例。
* **旋转**： *0.0 - 1.0*&#x200B;旋转整个形状。
* **曲线**： *-1.0 - 1.0*&#x200B;修改渐变配置文件曲线。
* **渐变**： *0.0 - 1.0*&#x200B;调整渐变对比度。
* **反转渐变**： *False/True*&#x200B;反转渐变方向。
* **自动缩放**： *False/True*&#x200B;缩放以适合使用默认设置的画布。
* **非正方形扩展**： *False/True*\
  启用以非方形比例补偿挤压和拉伸。
