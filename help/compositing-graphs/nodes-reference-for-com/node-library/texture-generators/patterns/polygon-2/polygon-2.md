## 描述

生成带有调整选项的平滑渐变多边形形状。 有关更高级的版本，请参阅[多边形1](../../../../../../compositing-graphs/nodes-reference-for-com/node-library/texture-generators/patterns/polygon-1/polygon-1.md)。

<a name="parameters"></a>

## 参数

|  |  |
|:---|:---|
| <b>边</b> <i>3 - 32</i> | 边数。 |
| <b>缩放</b> <i>0.0 - 1.0</i> | 设置全局缩放。 |
| <b>旋转</b> <i>0.0 - 1.0</i> | 旋转整个形状。 |
| <b>曲线</b> <i>-1.0 - 1.0</i> | 修改渐变配置文件曲线。 |
| <b>渐变</b> <i>0.0 - 1.0</i> | 调整渐变对比度。 |
| <b>反转渐变</b> <i>False/True</i> | 反转渐变方向。 |
| <b>自动缩放</b> <i>False/True</i> | 使用默认设置缩放以适合画布。 |
| <b>非正方形扩展</b> <i>False/True</i> | 启用以非方形比例补偿挤压和拉伸。 |
