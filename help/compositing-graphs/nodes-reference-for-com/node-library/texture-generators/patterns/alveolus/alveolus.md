## 描述

一种软球图案，可交替生成六边形拼贴。

## 参数

* **拼贴**： *1 - 16*\
  设置结果应平铺的次数。
* **渐变填充细胞**： *False/True*&#x200B;切换到锐化边缘，制作锐化的六边形拼贴。
* **间隙宽度**： *0.0 - 1.0*&#x200B;仅当上述选项设置为“False”时才有效。 更改间隙大小。
* **非正方形扩展**： *False/True*\
  启用以非方形比例补偿挤压和拉伸。
