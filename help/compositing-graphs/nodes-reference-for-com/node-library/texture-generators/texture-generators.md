# 纹理生成器

纹理生成器是不需要任何输入的节点：它们从头开始完全生成图像。 您可以将“纹理生成器”视为“procedurals”的另一种说法。

它们分为两类：

* [噪声](../../../../compositing-graphs/nodes-reference-for-com/node-library/texture-generators/noises/noises.md)\
  噪声是真正的程序化图形、随机形状和像素，例如著名的Perlin和云彩噪声。
* [图案](../../../../compositing-graphs/nodes-reference-for-com/node-library/texture-generators/patterns/patterns.md)\
  图案大多是看起来像是人造的形状，并且带有许多额外的控件来随机化它们。
