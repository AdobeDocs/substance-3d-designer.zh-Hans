# 样条曲线工具

样条曲线工具是一个节点集合，用于生成和调整样条，以及使用它们来映射、散布或变形图像。

样条曲线是平滑曲线，其轨迹由控制点和这些点的正切形成。 每个点还控制样条的Height和Thickness属性，这些属性用于驱动图像的映射、变形和散布。
