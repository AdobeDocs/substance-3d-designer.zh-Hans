# 样条桥（2条样条）

<table>
<tr style="border: 0;">
<td width="33.33%" style="border: 0;" valign="top">

![节点图标](../../../../../../assets/spline-bridge-2splines-icon.png "节点图标")

<b>In：</b>样条和路径工具>样条曲线工具

</td>
<td width="100.00%" style="border: 0;" valign="top">

## 描述

沿这些样条生成从<b>样条#1</b>到<b>样条#2</b>的样条。 生成的样条可以是线性（直线）或立方贝塞尔曲线（曲线）。

</td>
</tr>
</table>

>[!IMPORTANT]
>
> 如果提供给<b>样条#1</b>和<b>样条#2</b>输入的数据包含多个样条，则仅使用每个列表中的最后一个样条。

## 输入连接器

<b>预览#1</b> *灰度*&#x200B;输入样条#1预览为灰度图像。

<b>样条坐标#1</b> *颜色*&#x200B;输入样条点的坐标#1编码在彩色图像的RGBA通道中。\
<b>R</b> - X位置\
<b>G</b> - Y位置\
<b>B</b> -Height\
<b>A</b> — 打包的数据：\
*符号：样条是封闭的（负）或开放的（正）；\
*绝对值：Thickness+ 1。

<b>样条数据#1</b> *颜色*&#x200B;输入样条的其他数据#1编码在彩色图像的RGBA通道中。\
<b>R</b> — 切线X\
<b>G</b> — 切线Y\
<b>B</b> — 未使用\
<b>A</b> — 未使用

<b>样条量#1</b> *整数*&#x200B;输入样条#1数。

<b>预览#2</b> *灰度*&#x200B;输入样条#2预览为灰度图像。

<b>样条坐标#2</b> *颜色*&#x200B;以彩色图像的RGBA通道编码的输入样条#2点的坐标。\
<b>R</b> - X位置\
<b>G</b> - Y位置\
<b>B</b> -Height\
<b>A</b> — 打包的数据：\
*符号：样条是封闭的（负）或开放的（正）；\
*绝对值：Thickness+ 1。

<b>样条数据#2</b> *颜色*&#x200B;输入样条的其他数据#2编码在彩色图像的RGBA通道中。\
<b>R</b> — 切线X\
<b>G</b> — 切线Y\
<b>B</b> — 未使用\
<b>A</b> — 未使用

<b>样条量#2</b> *整数*&#x200B;输入样条#2数。

<b>起始切线长度曲线</b> *灰度*（在“桥样条类型”设置为“立方贝塞尔曲线”时可用）使用该图像第一行像素的值描述曲线。\
此输入用于控制沿样条曲线生成的每个样条的起始点的“出”切线的长度#1\
可以使用“曲线”节点创建曲线。

<b>开始切线旋转曲线</b> *灰度*（在“桥样条类型”设置为“立方贝塞尔曲线”时可用）使用该图像第一行像素的值描述曲线。\
此输入用于控制每个生成的样条的“出”切线沿样条#1的起始点的旋转。\
图像的灰度值表示若干转弯。\
可以使用“曲线”节点创建曲线。

<b>结束切线长度曲线</b> *灰度*（在“桥样条类型”设置为“立方贝塞尔曲线”时可用）使用该图像第一行像素的值描述曲线。\
此输入用于控制沿样条曲线生成的每个样条的端点的“in”切线的长度#2\
可以使用“曲线”节点创建曲线。

<b>末端切线旋转曲线</b> *灰度*（在“桥样条类型”设置为“立方贝塞尔曲线”时可用）使用该图像第一行像素的值描述曲线。\
此输入用于控制每个生成的样条沿样条#2的端点的“in”切线的旋转。\
图像的灰度值表示若干转弯。\
可以使用“曲线”节点创建曲线。

## 输出连接器

<b>预览</b> *灰度*&#x200B;输出样条作为灰度图像的预览。

<b>样条坐标</b> *颜色*&#x200B;以彩色图像的RGBA通道编码的输出样条点的坐标。\
<b>R</b> - X位置\
<b>G</b> - Y位置\
<b>B</b> -Height\
<b>A</b> — 打包的数据：\
*符号：样条是封闭的（负）或开放的（正）；\
*绝对值：Thickness+ 1。

<b>样条数据</b> *颜色*&#x200B;以彩色图像的RGBA通道编码的输出样条的附加数据。\
<b>R</b> — 切线X\
<b>G</b> — 切线Y\
<b>B</b> — 未使用\
<b>A</b> — 未使用

<b>样条量</b> *整数*&#x200B;输出样条的数量。

## 参数

<b>桥样条数量</b> *整数*&#x200B;沿样条#1向样条#2生成的样条数。

<b>桥样条类型</b> *整数*&#x200B;生成的样条类型：
* 线性：从起点到终点的直样条；
* 三次贝塞尔曲线：从起点到终点的曲线样条，曲线由起点和终点的长度和角度控制。

<b>启动样条#1</b> *浮动*&#x200B;沿样条#1从生成样条的位置偏移。 该值是“样条#1”的规范化长度。\
值越高，相同数量的样条就会排列得越紧密。

<b>启动样条#2</b> *浮动*&#x200B;沿样条#2从生成样条的位置偏移。 该值是“样条#2”的规范化长度。\
值越高，相同数量的样条就会排列得越紧密。

<b>结束样条#1</b> *浮动*&#x200B;沿样条向#1偏移位置，直至生成样条的位置。 该值是“样条#1”的规范化长度。\
值越低，相同数量的样条就会越紧密地排列在一起。

<b>结束样条#1</b> *浮动*&#x200B;沿样条向#2偏移位置，直至生成样条的位置。 该值是“样条#2”的规范化长度。\
值越低，相同数量的样条就会越紧密地排列在一起。

<b>偏移样条#1</b> *浮动*&#x200B;将偏移应用于样条线#1上所有样条的起始点。 该值是“样条#1”的规范化长度。\
与样条起点或终点相交的样条留在此处。

<b>偏移样条#2</b> *浮动*&#x200B;将偏移应用于样条线#2上所有样条的起始点。 该值是“样条#2”的规范化长度。\
与样条起点或终点相交的样条留在此处。

<b>偏移随机起始</b> *浮动*&#x200B;沿样条线#1对每个样条的起始点应用随机偏移。 该值是“样条#1”上样条之间的规范化距离。\
当保持为0时，样条在“起始样条”#1点和“终止样条”#1点之间均匀隔开。

<b>偏移随机结束</b> *浮动*&#x200B;将随机偏移应用于沿样条#2的每个样条的终点。 该值是“样条#2”上样条之间的规范化距离。\
当保持为0时，样条在“起始样条”#2点和“终止样条”#2点之间均匀隔开。

<b>切线长度起始</b> *浮点* （当“桥样条类型”设置为“立方贝塞尔曲线”时可用）所有生成样条的样条上#1点起点的“输出”切线的长度。

<b>切线长度结束</b> *浮点* （当“桥样条类型”设置为“立方贝塞尔曲线”时可用）所有生成样条的样条上#2端点“in”切线的长度。

<b>切线旋转开始</b> *浮点* （当“桥样条类型”设置为“立方贝塞尔曲线”时可用）所有生成样条的样条上#1点的“输出”切线的旋转。\
该值为匝数。

<b>切线旋转结束</b> *浮点*（在“桥样条类型”设置为“立方贝塞尔曲线”时可用）所有生成样条的样条上终点#2的“in”切线的旋转。\
该值为匝数。

+++预览
<b>段数量</b> *整数*&#x200B;调整用于在预览输出中绘制样条可视化效果的段数。\
值越高，线条越平滑。

<b>显示方向帮助程序</b> *布尔值*&#x200B;在预览输出中，在样条线的起始处显示一个点，在其结尾处显示一个箭头。

<b>显示Thickness信封</b> *布尔值*\
在样条Thickness的边显示附加线。

<b>Thickness（像素）</b> *浮动*&#x200B;以像素为单位调整样条可视化在预览输出中的Thickness。
