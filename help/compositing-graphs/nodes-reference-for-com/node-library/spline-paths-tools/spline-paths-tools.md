# 样条和路径工具

样条和路径工具是一个节点集合，用于在图形中使用路径和样条：

<b>路径</b>是一系列连接到直线上的点。

<b>样条</b>是平滑曲线，其轨迹由控制点和这些点的切线形成。 每个点还控制样条的Height和Thickness属性，这些属性用于驱动图像的映射、变形和散布。

此类别包含以下子类别：

* [样条曲线工具](../../../../compositing-graphs/nodes-reference-for-com/node-library/spline-paths-tools/spline-tools/spline-tools.md)\
  用于生成和调整样条以及使用这些样条进行映射、散布或变形图像的节点。
* [路径工具](../../../../compositing-graphs/nodes-reference-for-com/node-library/spline-paths-tools/path-tools/path-tools.md)用于生成和调整路径，以及将其转换为样条以实现复杂的图像散布或变形的节点。
