## 描述

这是一个快速预设助手节点，可返回一些预定义的&#x200B;**纯**&#x200B;金属的正确反射颜色。 它可以用于金属模型的基色，也可以用于Specular/光泽度模型的Specular通道。

当需要纯金属的起始点时，此节点非常有用，可让您避免从图表中进行拾色。

## 参数

* **金属颜色**：*金、银、铝、铁、铜、钛、镍、钴、铂*&#x200B;选取预定义的金属值。
