# pbr金属反射率

</td>

## 描述

这是一个快速的“预设”帮助器节点，可返回一些预定义的&#x200B;**纯**&#x200B;金属的正确反射颜色。 它可用于金属模型的基色，或用于Specular/光泽度模型的Specular通道。

当需要纯金属的起始点时，此节点非常有用，可让您避免从图表中进行拾色。
