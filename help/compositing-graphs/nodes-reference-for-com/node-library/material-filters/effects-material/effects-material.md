# 效果（材质）

此类别包含可生成完全成熟素材效果的节点，类似于[风化](../../../../../compositing-graphs/nodes-reference-for-com/node-library/mesh-based-generators/weathering/weathering.md)节点的工作方式，但主要区别在于这些“效果”节点可以将任何素材作为输入。 它们还需要已烘焙贴图作为输入，大多是高度图。

两个很好的示例是[水位](../../../../../compositing-graphs/nodes-reference-for-com/node-library/material-filters/effects-material/water-level/water-level.md)和[Snow覆盖](../../../../../compositing-graphs/nodes-reference-for-com/node-library/material-filters/effects-material/snow-cover/snow-cover.md)。
