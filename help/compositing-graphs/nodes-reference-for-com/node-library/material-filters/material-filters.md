# 材质滤镜

材质过滤器是使用完整材料输入的节点：多个通道的组合，最好通过[链接创建模式](../../../../interface/the-graph-view/link-creation-modes/link-creation-modes.md)使用。 无论您使用的是完整的PBR素材，而不是仅使用单个通道（如基色或正常）或简单的黑白蒙版，您都需要使用素材滤镜类别。

此类别由若干子类别组成：

* [一键式](../../../../compositing-graphs/nodes-reference-for-com/node-library/material-filters/1-click/1-click.md)\
  仅包含Bitmap2材料。
* [效果](../../../../compositing-graphs/nodes-reference-for-com/node-library/material-filters/effects-material/effects-material.md)\
  精美的一体化材料效果。
* [变换](../../../../compositing-graphs/nodes-reference-for-com/node-library/material-filters/transforms-material/transforms-material.md)\
  多渠道转换助手。
* [混合](../../../../compositing-graphs/nodes-reference-for-com/node-library/material-filters/blending-material/blending-material.md)\
  多通道混合节点。
* [PBR实用工具](../../../../compositing-graphs/nodes-reference-for-com/node-library/material-filters/pbr-utilities/pbr-utilities.md)\
  PBR助手节点和工具。
* [扫描处理](../../../../compositing-graphs/nodes-reference-for-com/node-library/material-filters/scan-processing/scan-processing.md)\
  专门用于照相扫描纹理的工具。
