# 混合（材质）

“混合”类别是最重要的多通道素材类别之一。 它包含用于组合、切换和混合由多个同时输出组成的材料的节点。

这些节点可以节省大量工作，但请确保您完全了解[链接创建模式](../../../../../interface/the-graph-view/link-creation-modes/link-creation-modes.md)以正确使用它们。
