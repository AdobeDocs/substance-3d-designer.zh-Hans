## 描述

调整输入图像的曝光度。 使用“色标”值概念使HDR照片变亮或变暗，就像在照片编辑软件中一样。

## 参数

* **曝光(EV)** ： *-8.0 - 8.0*&#x200B;曝光值，以秒为单位。
