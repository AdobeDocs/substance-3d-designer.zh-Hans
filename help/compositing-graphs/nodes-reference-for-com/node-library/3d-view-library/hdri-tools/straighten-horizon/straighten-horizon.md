<a name="parameters"></a>

## 参数

|  |  |
|:---|:---|
| <b>启用水平校正</b> <i>False/True</i> | 启用和禁用效果。 允许切换以比较前后并查找正确的点。 |
| <b>水平点#1位置</b> | 第一个点有2D 视图手柄。 |
| <b>水平点#2位置</b> | 第二点，有2D 视图手柄。 |
| <b>水平旋转</b> <i>0.0 - 1.0</i> | 额外围绕中心轴旋转。 |
