## 描述

对于水平线不直的HDRI，此节点提供了一种简单、用户友好的方法来纠正此问题。

## 参数

* **启用水平校正**： *False/True*\
  启用和禁用效果。 允许切换以比较前后并查找正确的点。
* **水平点#1位置**：\
  第一个点有2D 视图手柄。
* **水平点#2位置**：\
  第二点，有2D 视图手柄。
* **水平旋转**： *0.0 - 1.0\
  额外围绕中心轴旋转。*
