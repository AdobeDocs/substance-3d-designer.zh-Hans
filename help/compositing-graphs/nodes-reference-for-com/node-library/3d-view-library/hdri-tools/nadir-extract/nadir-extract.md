## 描述

提取球面映射输入图像的中心地点（最低点）。 可用于将一张图像的最低点传输到另一张图像，蒙版相机和三脚架。

## 参数

* **缩放**： *0.0 - 10.0*\
  设置地点的“缩放级别”
* **旋转**： *0.0 - 1.0*\
  围绕中心轴旋转。
* **输出灰度系数**： *sRGB，线性*&#x200B;输出灰度系数。
