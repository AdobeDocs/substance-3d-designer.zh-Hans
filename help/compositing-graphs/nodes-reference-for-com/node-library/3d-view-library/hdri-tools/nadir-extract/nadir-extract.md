## 描述

提取球面映射输入图像的中心地面点（最低点）。 可用于将一张图像的最低点转移到另一张图像，遮盖相机或三脚架。

<a name="parameters"></a>

## 参数

|  |  |
|:---|:---|
| <b>缩放</b> <i>0.0 - 10.0</i> | 设置地面点的“缩放级别” |
| <b>旋转</b> <i>0.0 - 1.0</i> | 围绕中心轴旋转。 |
| <b>输出灰度系数</b> <i>sRGB，线性</i> | 输出灰度系数。 |
