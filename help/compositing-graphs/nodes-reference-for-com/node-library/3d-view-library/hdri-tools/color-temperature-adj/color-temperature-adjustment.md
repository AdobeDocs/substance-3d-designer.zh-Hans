## 描述

调整输入图像的色彩平衡。 与摄影中的“白平衡”调整类似。 可用于在HDR非关键图像中使用暖色或冷色。

## 参数

* **温度**： *-1.0 - 1.0*\
  在暖色和冷色之间转换颜色。
* **洋红 — 绿**： *-1.0 - 1.0*\
  调整洋红色和绿色之间的色调。
* **色彩空间**： *HDR（线性），LDR (sRGB)*确定输入图像色彩空间的解释方式。
