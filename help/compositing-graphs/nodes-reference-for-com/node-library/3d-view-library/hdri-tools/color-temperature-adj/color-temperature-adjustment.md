## 描述

调整输入图像的色彩平衡。 与摄影中的“白平衡”调整类似。 可用于在HDR非关键图像中使用暖色或冷色。

</td>
</tr>
</table>

<a name="parameters"></a>

## 参数

|  |  |
|:---|:---|
| <b>温度</b> <i>-1.0 - 1.0</i> | 在暖色和冷色之间转换颜色。 |
| <b>洋红 — 绿</b> <i>-1.0 - 1.0</i> | 调整洋红色和绿色之间的色调。 |
| <b>色彩空间</b> <i>HDR（线性），LDR (sRGB)</i> | 确定如何解释输入图像的色彩空间。 |
