</td>

## 描述

合并多个摄影曝光以创建高动态范围图像。 第一个输入是曝光最不足的图像。

## 输入

* **Input 1-**** 16**： *颜色输入*输入图像。 可用数量取决于参数。

## 参数

* **输入**： *2 - 16*\
  设定可用输入值。
* **曝光增量(EV)**： *0.0 - 4.0*\
  设置不同图像之间解释的曝光度差异。
* **白场**： *0.0 - 13.0*&#x200B;设置白场以对最终结果执行一些调整。
