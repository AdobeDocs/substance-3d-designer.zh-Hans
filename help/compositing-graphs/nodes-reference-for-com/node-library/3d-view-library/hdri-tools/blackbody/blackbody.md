## 描述

将开氏坐标中的色温转换为RGB。 较低的Kelvin值表示更暖的颜色，较高的Kelvin值表示更冷的颜色。

## 参数

* **温度**： *1000.0 - 27000.0*&#x200B;确定颜色的开氏值。
