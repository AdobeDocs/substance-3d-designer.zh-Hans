## 描述

围绕输入球面映射的全景图图像的中心点旋转该图像，从而保持投影/映射的正确性。 用于倾斜或调整HDRI图像。

## 参数

* **旋转**： *0.0 - 1.0*
* **方向角度**： *0.0 - 1.0*
* **围绕极点预旋转**： *-1.0 - 1.0*
* **围绕极点旋转后**： *0.0 - 1.0*
