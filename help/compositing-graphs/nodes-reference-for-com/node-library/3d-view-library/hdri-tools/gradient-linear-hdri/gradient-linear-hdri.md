## 描述

创建一个位于中心且包含用户放置点的线性渐变。 与常规[渐变线性1](../../../../../../compositing-graphs/nodes-reference-for-com/node-library/texture-generators/patterns/gradient-linear-1/gradient-linear-1.md)不同，最终结果会针对球面投影进行调整。

## 参数

* **点位置**：\
  用于确定渐变方向的点的位置。
* **顶部颜色**： *（颜色值）*\
  渐变顶部的颜色（在点处）
* **底色**： *（颜色值）*\
  渐变底部颜色（远离点）。
* **对比度**： *0.0 - 1.0*\
  调整结果的对比度。
