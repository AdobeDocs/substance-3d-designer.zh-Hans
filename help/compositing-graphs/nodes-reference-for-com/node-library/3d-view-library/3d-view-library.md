# 3D视图（库）

“3D视图”类别仅包含与球面投影HDRI相关的节点，这些节点要么用于Substance 3D Designer的3D视图，要么用于导出到其他应用程序，如Substance 3D Painter。

有两个子类别：

* **HDRI环境**：无文档可用，因为这些是纯图像，旨在在3D视图中显示，没有附加参数。
* **HDRI 工具**：用于创建和编辑球面HDRI图像的工具节点。 在SD 2019.2中引入。
