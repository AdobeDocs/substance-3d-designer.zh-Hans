# 基于网格的生成器

基于网格的生成器是旨在处理[已烘焙贴图](../../../../bakers/bakers.md)的节点，如法线图、弯曲、Ambient occlusion等。

此类别的名称来源于已烘焙贴图是Designer使用基于3D网格数据的唯一方式。 此类别中的相当一部分功能类似于Substance 3D Painter中的[智能材质和蒙版](https://experienceleague.adobe.com/en/docs/substance-3d-painter/using/features/smart-materials-and-masks)。

主要分为三类：

* [蒙版生成器](mask-generators/mask-generators.md)\
  基于一个或多个已烘焙贴图的黑白色蒙版生成器。
* [风化](weathering/weathering.md)
基于已烘焙贴图的全材料风化效果。
* [实用工具](utilities-mesh-based-gen/utilities-mesh-based-generators.md)\
  用于处理烘焙的额外实用程序和工具。
