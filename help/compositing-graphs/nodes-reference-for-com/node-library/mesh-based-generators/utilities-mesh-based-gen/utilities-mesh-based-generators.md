# 公用事业（基于网格的发电机）

这些节点是更抽象的工具，可帮助您处理网格自适应节点。 在某些情况下，它们的功能还与[材质过滤器](../../../../../compositing-graphs/nodes-reference-for-com/node-library/material-filters/material-filters.md)紧密关联。

此类别中只有少数节点，因此请确保将它们全部检出。
