## 描述

根据已烘焙贴图和用户设置生成黑白蒙版。 这几乎是Painter蒙版生成器的Designer版本。

它是一种复杂的工具，旨在作为基于已烘焙贴图、用户参数和污渍模式及地图的全方位蒙版生成器。 它主要是作为一个非常先进的、完全控制的节点，用于混合折痕Dirt和边缘磨损。 此节点功能强大，足以模拟其他所有蒙版生成器。

没有明确要求的烘焙，但您提供的越多，此节点所能执行的操作就越多。

## 参数

### 输入

* **环境遮蔽**： *灰度输入*
* **曲率**： *灰度输入*
* **正常世界空间**： *颜色输入*
* **污渍输入**： *灰度输入*
* **污渍输入2**： *灰度输入*
* **输入**&#x200B;散点： *灰度输入*\
  自定义散点图章，使用散点参数时需要使用该图章。
* **蒙版（可选）**： *灰度输入*\
  用于遮盖节点效果的遮罩槽。
* **位置**： *颜色输入*\
  用于三平面和上下效果。

### 参数

* **级别**： *0.0 - 1.0*\
  设置效果的总级别，逐渐显示出来。
* **对比度**： *0.0 - 1.0*\
  调整结果的对比度。
* **反转**： *False/True*\
  反转结果。 有助于实现与所构建蒙版相反的效果。
* **使用三平面**： *False/True*&#x200B;启用三平面投影，避免与污渍映射出现任何接缝。
* **三平面混合对比度**： *0.0 - 1.0*&#x200B;设置三平面混合的对比度。
* **污渍**： *0.0 - 1.0*&#x200B;设置要全局混合的污渍量。
* **污渍**
  * **比例**： *0 - 10*&#x200B;设置全局污渍的比例。
  * **使用自定义污渍**： *False/True*&#x200B;启用自定义污渍输入。
  * **辅助自定义污渍**： *0.0 - 1.0*&#x200B;启用第二个自定义污渍输入。
  * **反转**： *False/True*\
    反转污渍映射。
* **AO**： *-1.0 - 1.0*&#x200B;设置此效果应在被遮挡的AO区域中出现的范围。 可使用以下组进行调整。
* **AO**
  * **范围**： *0.0 - 1.0*&#x200B;设置Dirt外观的阈值或范围。
  * **对比度**： *0.0 - 1.0*\
    调整AO效果的对比度。
  * **杂色**： *0.0 - 1.0*&#x200B;设置要混合到AO效果的杂色/污渍量。
  * **噪声比例**： *0 - 10*&#x200B;设置AO噪声/污渍的比例。
  * **噪声类型**：*斑点、云、水汽、白噪声*&#x200B;在4种不同类型的AO噪声之间切换。
  * **反转**： *False/True*\
    反转AO图的解释：噪点将出现在AO亮区，而不是暗区。
* **曲率**： *0.0 - 1.0*&#x200B;设置应在曲率边缘上显示多少效果；可以是凸的和凹的。 用下面的组稍作调整。
* **曲率**
  * **凸形范围**： *-1.0 - 1.0*&#x200B;设置凸形（明亮）曲率边缘要呈现多大的效果。
  * **凸对比度**： *0.0 - 1.0*&#x200B;设置凸形效果的对比度。
  * **凸反转**： *False/True*&#x200B;反转凸边缘的解释。
  * **凹形范围**： *-1.0 - 1.0*&#x200B;设置凹形（暗）曲率边缘上出现的效果程度。
  * **凹形对比度**： *0.0 - 1.0*&#x200B;设置凹形范围的对比度。
  * **凹形反转**： *False/True*&#x200B;反转凹形边缘的解释。
  * **Smoothness**： *0.0 - 16.0*&#x200B;应用于曲率边缘的模糊和平滑量。
  * **Level Boost**： *0.0 - 1.0*&#x200B;如果效果不够明显，则添加额外增强器。
  * **杂色**： *0.0 - 1.0*&#x200B;设置杂色/污渍对曲率效果的影响。
  * **噪声比例**： *0 - 10*&#x200B;设置噪声的比例。
  * **噪声类型**：*斑点、云、水汽、白噪声*&#x200B;从4种不同的噪声类型中进行选择。
* **上/下渐变**： *-1.0 - 1.0*&#x200B;使用基于位置映射的上/下渐变混合或蒙版。 正值使图像变得更亮，负值会掩盖现有效果。
* **渐变**
  * **范围**： *0.0 - 1.0*&#x200B;设置渐变的位置。
  * **对比度**： *0.0 - 1.0*\
    调整渐变的对比度。
  * **反转**： *False/True*\
    反转渐变。 有效地交换底部和顶部。
* **世界空间法线**： *0.0 - 1.0*&#x200B;类似于“上/下渐变”，但具有位置地图和六个方向，类似于“假光照”。 正值调亮，负值调暗。
* **世界空间正常**
  * **顶部强度**： *-1.0 - 1.0*
  * **底部强度**： *-1.0 - 1.0*
  * **前部强度**： *-1.0 - 1.0*
  * **背部强度**： *-1.0 - 1.0*
  * **右侧强度**： *-1.0 - 1.0*
  * **左侧强度**： *-1.0 - 1.0*
* **Scratches**： *-1.0 - 1.0*&#x200B;将划痕混合到白色区域。
* **Scratches**
  * **数量**： *0 - 4096*&#x200B;设置划痕的总量。
  * **比例**： *0.0 - 1.0*&#x200B;设置单个划痕的比例。
* **散点**： *-1.0 - 1.0*&#x200B;在白色区域内散点自定义图章。
* **散点**
  * **比例**： *0 - 50*&#x200B;效果的总比例。
  * **密度**： *0.0 - 1.0*&#x200B;应显示的散布密度控制数。
  * **大小**： *0.0 - 4.0*&#x200B;散布图章的大小。
  * **大小变化**： *0.0 - 1.0*&#x200B;图章大小内的变化。
  * **不透明度变化**： *0.0 - 1.0*&#x200B;图章不透明度内的变化。
