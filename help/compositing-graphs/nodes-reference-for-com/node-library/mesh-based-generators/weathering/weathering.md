# 风化

风化节点使[蒙版生成器](../../../../../compositing-graphs/nodes-reference-for-com/node-library/mesh-based-generators/mask-generators/mask-generators.md)更进一步：它们根据参数和已烘焙贴图实现全素材风化效果。 概念与[智能素材](https://experienceleague.adobe.com/en/docs/substance-3d-painter/using/features/smart-materials-and-masks)的Substance Painter非常相似。

您需要有一个或多个已烘焙贴图才能从这些节点获得完整结果。

请记住，由于这些节点提供此类全方位的、完整的效果，因此它们的使用仅限于某些情况。 但是，它们也可为学习如何构建这种复杂效果打下良好的基础。 将节点从库拖到浏览器中，或者右键单击并选择图形中某个节点上的“打开参照”。
